# ДРАКОН-лист: дерево задач, шаг 2 (факты → JSON с тритом «проверено»)

Код — `komanda/derevo/derevo.py`, ядро — `yadro-trit/trit.py`, факты — `komanda/derevo/derevo.pl`.
Правится только derevo.pl; `derevo.json` собирается программой (листок Е.8 № 28). Программа в сеть не ходит.
Правильность дерева (цикл, чужой родитель, чужой статус) проверяет `proverka.pl` на стенде, не этот код.

## Действия

```дракон
название: Сборка дерева задач
ввод: список репозиториев (gh repo list Scatik146 --json name,pushedAt,isArchived --limit 200), derevo.pl
А = самопроверка: пример и контрпримеры
Б = пробы-мутанты: есть_ли, согласие испорчены в «да» — самопроверка говорит «нет»
сам = меньшее из А и Б, встроенным min
факты = строки derevo.pl: семь видов фактов схемы и статус/1; чужая строка — ошибка входа
узлы = узел/3 и их свойства; свойство без узла — ошибка входа
если: сам = да и ошибок входа нет
  да:
    для каждого узла и каждого его источника — по шагам ниже
    если: источник github и список репозиториев есть
      да:
        есть = есть_ли(нашёл, полный) — «нет» только по полному списку
        спор = согласие(статус жив, репозиторий жив) — разное даёт «не знаю»
        трит источника = есть и спор
      нет:
        трит источника = не знаю
    проверено = меньшее по источникам узла; без источника — не знаю
    итог = меньшее по узлам, встроенным min
    записать derevo.json
    вывод: сводка; код выхода: да 0, нет 1, не знаю 2
  нет:
    вывод: «не знаю» и ошибки входа; derevo.json не трогать; код выхода 2 (самопроверка «нет» — 1)
```

## Данные

```конспект
тема: Трит «проверено» узла дерева задач
связка: собрано из
проверено -> есть_ли, согласие, min встроенный
есть репозиторий -> есть_ли
статус согласен -> согласие
итог -> min встроенный
стрелка: «работает у нас», «в работе» — жив; «заморожено», «завершено» — не жив; «идея» — не знаю
стрелка: живой статус и пушей нет больше 60 дней — не знаю (№ 37)
стрелка: замороженный статус и пуш свежее 14 дней — не знаю (№ 9)
стрелка: нет источника, sourcecraft, путь внутри репозитория — не знаю (№ 5, 46)
стрелка: «да» — только если репозиторий есть и статус согласен (№ 15)
```

## Тест

- пример: `узел(a, корень, работает_у_нас)`, `github('Scatik146/zhivoj')`, пуш 6 дн. назад → «да»
- пример: `узел(c, a, заморожено)`, тот же репозиторий → «не знаю» (№ 9)
- пример: `узел(f, a, в_работе)`, пуш 1.01.2026 → «не знаю» (№ 37)
- пример: узел без источника, узел с `sourcecraft(…)` → «не знаю»
- пример: нет списка репозиториев → итог «не знаю», код выхода 2
- контрпример: `github('Scatik146/net-takogo')` при полном списке → «нет», не «не знаю» и не «да»
- контрпример: строка `узел(x, y).` (два аргумента) → ошибка входа «строка 2: не факт схемы», JSON не пишется
- контрпример: `название(z, 'нет')` без узла z → ошибка входа
- контрпример: ответ GitHub `{"message": "403"}` вместо списка → не список, «не знаю»
- контрпример: в копии ядра `есть_ли` или `согласие` = всегда «да» → самопроверка «нет», код выхода 1

## Пополнение словаря

`имя — слой — что делает — из каких слов собрано`

- `chitat` — нижний — текст файла или пустая строка — встроенные
- `znachenie`, `argumenty`, `pustaya`, `fakt`, `fakty` — нижний → средний — строка Prolog → (имя, аргументы); ошибки по номерам строк — re
- `pustoj_uzel`, `svojstvo`, `uzly` — средний — факты → узлы со свойствами — fakty
- `zapis_repo`, `spisok_repo`, `repozitorii` — нижний — список gh или REST → имя → (дата пуша, архив) — json, datetime
- `zhiv_repo`, `soglasno`, `prichina_spora` — средний — жив ли репозиторий по мерке статуса; согласие ядра — trit.согласие
- `est_li` — средний — есть ли репозиторий — trit.есть_ли
- `github`, `istochnik`, `provereno` — верхний — трит узла и причины по номерам листка Е.8 — est_li, soglasno, min
- `sobrat`, `derevo` — верхний — факты и список → JSON-словарь и ошибки входа — fakty, uzly, provereno
- `primery`, `samoproverka`, `proba_mutanta` — верхний — пример, контрпримеры, мутанты ядра — derevo, min
- `schet`, `zapisat`, `svodka`, `kod_vyhoda`, `glavnoe` — верхний — сводка, запись, код выхода — всё выше
