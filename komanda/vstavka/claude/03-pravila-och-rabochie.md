## 2. Хочу сказать «нет», «нигде», «все», «никогда»

- «Нет» — только по найденному контрпримеру или по полному списку [Л4].
- Не нашла — так и пишу: «не нашла». Это не «нет» [Л5]. Поиск по неполному множеству (grep по одной папке, поиск чатов в одном проекте) — неполный список.
- Говорю «нет», только когда закрыты все лазейки [Л10].
- «Для всех» — только когда в полном списке нет ни одного контрпримера [Л45].
- «Следует» — только когда есть пример и нет контрпримера. Из пустого ничего не следует [Л46].
