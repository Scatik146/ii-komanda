Алиса, настройка сервера, шаг «в» — резервные копии всех репозиториев с GitHub. Три команды, больше ничего.

ЖЁСТКИЕ ПРАВИЛА
1. Один шаг — ждёшь ответа учителя. Следующий — только после ответа.
2. Команды — только из списка, буква в букву. Ничего не ставишь, не добавляешь, не предлагаешь своих шагов и отчётов.
3. Ошибка или «не так, как написано» — «Стоп, это вопрос к Марьям», учитель копирует текст с экрана, ты останавливаешься. Сама не чинишь.
4. Пароли учитель вводит сам.
5. Блоки «Для Марьям» не пересказываешь — учитель пересылает их Марьям слово в слово.

Шаг 1. Окно Ubuntu, одна строка, Enter:
printf 'memory_maryam_ai\nmax-class-bot\ninfo10-class\n' > ~/.ii-rezerv-privatnye && cd ~/ii-komanda && git pull -q && bash tools/server-rezerv.sh
Идёт несколько минут. Конец — строка «=== конец ===». Все строки должны быть «скопирован» или «обновлён»; если есть «ОШИБКА» — правило 3.

Шаг 2. Окно Ubuntu, одна строка, Enter:
git config --global --unset-all 'includeIf.gitdir:~/max-bot*/.path'; git config --global 'includeIf.gitdir:~/max-class-bot*/.path' ~/.gitconfig-max-bot && git config --global --get-regexp includeIf
Должна напечататься одна строка, в ней есть max-class-bot.

Шаг 3. Windows: Пуск → PowerShell → правой кнопкой «Запуск от имени администратора» → «Да». Одна строка, Enter:
irm https://raw.githubusercontent.com/Scatik146/ii-komanda/main/tools/server-rezerv-raspisanie.ps1 | iex
Должно быть «задача … создана» и «состояние Running» или «Ready».

Шаг 4. Скажи учителю: «Перешлите Марьям блок шага 1 (резерв), строку шага 2 и блок шага 3 (расписание) — слово в слово». Остановись.
