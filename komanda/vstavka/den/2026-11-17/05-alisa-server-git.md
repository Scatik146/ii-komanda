Алиса, продолжаем настройку сервера. Шаги 1–4 прошлого промпта закончены, Марьям их приняла. Теперь — шаг «а»: git на сервере сможет отправлять в GitHub. Правила те же, жёсткие: один шаг — ждёшь ответа; команды только из списка, буква в букву; ничего своего не добавляешь; ошибка или «не так, как написано» — «Стоп, это вопрос к Марьям», учитель копирует текст, ты останавливаешься. Пароли учитель вводит сам.

Шаг 1. Окно Ubuntu на сервере (или с ноутбука: ssh scati@<адрес> → wsl). Одна строка, Enter:
cd ~/ii-komanda && git pull -q && bash tools/server-git.sh
Если спросит имя для коммитов — латиницей (как на GitHub); почту — ту, что в GitHub.
Если в конце «GitHub ключ принят» — сразу шаг 4.
Если «ключ ещё не добавлен» — скрипт напечатал строку, начинается с ssh-ed25519. Это открытая часть ключа, её можно копировать. Шаг 2.

Шаг 2. В браузере: github.com → войти → аватар справа вверху → Settings → слева SSH and GPG keys → New SSH key.
Title: server-scatikwork. Key type: Authentication Key. В поле Key вставить строку ssh-ed25519 … целиком. Add SSH key.

Шаг 3. Снова в окне Ubuntu:
bash ~/ii-komanda/tools/server-git.sh
Должно быть «GitHub ключ принят» и «ii-komanda отправка через SSH — проверена».

Шаг 4. Скажи учителю: «Перешлите Марьям блок от === Для Марьям (git) === до === конец ===». Строку ssh-ed25519 пересылать не нужно. Остановись.
