## Реализуемо ли

- **Двоичный** — всё делают серийно.
- **Троичный:**
  - вентили Т-КМОП (инвертор, защёлка памяти) сделаны на пластине [0];
  - троичные сумматоры есть пока **только в моделировании** (CNTFET, HSPICE) [0]. Изготовленного в кремнии я не нашла: по
    найденному это 0, а не «нельзя»;
  - ворота — это обычный «положительный/отрицательный троичный инвертор» из литературы (PTI/NTI) [условие: так их называю я,
    проверить по подлиннику].

## Логика тритов на двоичной машине «двумя проводами» (24.11, `dvuhprovodnaya.py` → `rezultat-logika.txt`)

Трит на битах — два провода (p, n): «да» = (1, 0), «не знаю» = (0, 0), «нет» = (0, 1). Тогда И = (p∧p′, n∨n′), НЕ —
поменять провода (даром), ворота = (p, ¬p). Слова книги на обеих машинах [счёт, проверено по 9 парам]:
И, ИЛИ — двоичный ×2 по транзисторам; НЕ — у двоичного даром; ворота, подтвердить — двоичный ×0,5; согласие ×1,0;
оба точно ×1,14; не знаю? ×0,8. **Вывод:** наша логика на двоичном железе стоит почти столько же, сколько на троичном.
Выигрыш троичной машины в логике — не больше постоянного множителя (провода и память: 1 трит против 2 бит), а не «много
сильнее». Сила логики осторожного человека — в том, что она **считает** («не знаю» вместо ложного «да»), а не в железе.

### Кто ещё предлагал (по выдаче поиска 24.11, подлинники не прочитаны → 0)

- Колсон (1726), Коши (1840) — цифры со знаком для ручного счёта (Википедия «Signed-digit representation», Кахори 1928).
- Авиженис, IRE Trans. EC-10 (1961), 389–400 — цифры со знаком для машины: сложение за время двух цифр при любой длине.
- SRT (Суини, Робертсон, Точер, 1958) — деление с цифрами частного −2…2 по таблице; в Pentium таблица была с пропусками —
  ошибка FDIV 1994, расход Intel $475 млн.
- Такаги, Ясуура, Ядзима, IEEE TC C-34 (1985) — умножитель: дерево сумматоров с цифрами −1, 0, 1, время ~log n.
- Mitsubishi (Макино и др., JSSC 1996) — умножитель 54×54, 8,8 нс, 78 800 транзисторов, 0,5 мкм.
- POSTECH (Lee, Bae, IEICE 2002) — 54×54, 43 579 тр., 6,9 нс, 0,25 мкм.
- Камеяма (JSSC 1988) — умножитель 32×32 на многозначных токовых схемах с цифрами со знаком: ~23 600 тр., площадь вдвое
  меньше двоичного, < 59 нс — **настоящий кристалл на «не двух» уровнях**.
- Перенос с сохранением (carry-save) — тоже избыточная двоичная запись (цифры 0, 1, 2); стоит в каждом умножителе
  (Википедия «Redundant binary representation», там же «citation needed»).
