# ДРАКОН-лист: сравнение двух калькуляторов (itog.py)

## Действия

```дракон
название: Сравнить калькуляторы
настроить слова тритов (luchshie.nastroit)
посчитать ширины: активация и сумма
для: для каждого варианта А, Б, В
  построить узлы обоих оснований и проверить на числах
вопрос: вариант А или В?
  да:
    посчитать действия над десятичными и сверить с Python
  нет:
    пропустить
посчитать задачу: K шагов MAC + сложение + умножение + округление
вывод: таблицы узлов, действий, задачи, памяти
```

## Данные

```конспект
тема: Два калькулятора
связка: двоичный | троичный
базис -> И, ИЛИ, НЕ | И, НЕ, ворота, 0
активация -> 8 бит | 6 тритов
сумма слоя -> 21 бит | 13 тритов
перенос полусумматора -> И | согласие
округление до степени основания -> одно сложение | даром
```

## Тест

- пример: ширина суммы для |x| ≤ 524 288 → 21 бит и 13 тритов
- контрпример: ширина суммы для |x| ≤ 524 288 → 20 бит
- пример: перенос троичного полусумматора (1, 1) → 1, (1, −1) → 0
- контрпример: перенос троичного полусумматора (1, −1) → −1
