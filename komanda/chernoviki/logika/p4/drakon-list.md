# ДРАКОН-лист: проверка схем с неизвестным X (proverka_x.py)

## Действия

```дракон
название: Проверить схемы с неизвестным
для: для каждой схемы: сумматор, умножитель 4×4, строка слоя a·b + c·d
  проверить исправную схему на всех наборах
  посчитать, куда уходит X от известного подозреваемого
  для: для каждой задачи А, Б, В
    точно: перебрать значения X
    способ 1: подменить X числом
    способы 2 и 3: прогнать с «не знаю» на двух проводах и на тритах
    вопрос: ответы способов 2 и 3 одинаковы?
      да:
        сосчитать ложные «да» и лишние «не знаю»
      нет:
        остановиться с ошибкой
  для: для каждого виновника
    получить, что выдал сломанный чип
    оставить подозреваемых каждым способом
    вопрос: точные подозреваемые есть среди наших?
      да:
        фильтр нашей логикой, потом перебор оставшихся
      нет:
        остановиться с ошибкой
вывод: таблицы мер, прогонов и работы
```

## Данные

```конспект
тема: Три способа увидеть X
связка: запись | ответ на X | беда
способ 1 -> биты, X = 0 | всегда уверен | ложное «да» (X-оптимизм)
способ 2 -> два провода (p, n), X = (0, 0) | «не знаю» | лишнее «не знаю» (X-пессимизм)
способ 3 -> триты, X = 0 | «не знаю» | то же, что способ 2
точно -> перебор X: 2 прогона на неизвестное | верно | прогонов много
```

## Тест

- пример: полный сумматор, a = X, b = 1, c = 1 → перенос точно 1; способ 3 говорит «не знаю»
- контрпример: полный сумматор, a = X, b = 1, c = 1 → способ 3 говорит «перенос 0»
- пример: полный сумматор, a = X, b = 1, c = 0 → способ 1 говорит «сумма 1», а на деле сумма может быть 0 или 1
- контрпример: полный сумматор, a = X, b = 0, c = 0 → способ 3 говорит «перенос не знаю»
