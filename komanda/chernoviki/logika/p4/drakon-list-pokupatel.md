# ДРАКОН-лист: чип с ошибкой у покупателя (pokupatel.py)

## Действия

```дракон
название: Проверить партию чипов на заводе
для: для каждой схемы: умножитель 4×4, строка слоя
  посчитать вред каждого дефекта на всех наборах
  убрать невидимые дефекты
  для: для каждой длины проверки T и каждого неизвестного: нет, вход b0, слово b
    для: для каждой из 20 партий
      выбрать T случайных наборов
      посчитать эталон четырьмя способами
      для: для каждого дефекта
        подать наборы на дефектный и на исправный чип
        вопрос: где эталон уверен, выход совпал?
          да:
            чип прошёл
          нет:
            чип выброшен
    напечатать: брак прошёл, годных выброшено, вред, прогонов эталона
напечатать: рост перебора 2^k
```

## Данные

```конспект
тема: Заводская проверка с неизвестным
связка: сравнивает | беда
1: биты, X → 0 -> все биты | выбрасывает годные
2 и 3: наша логика -> только уверенные биты | пропускает больше брака, чем перебор
точно: перебор -> только известные на деле | 2^k прогонов эталона
```

## Тест

- пример: умножитель, неизвестен вход b0, T = 32 → способ 1 выбрасывает все годные чипы
- контрпример: умножитель, неизвестен вход b0, T = 32 → наша логика выбрасывает годный чип
- пример: без неизвестного → все четыре способа пропускают одинаково
- контрпример: строка слоя, неизвестен b0, T = 64 → наша логика пропускает брака меньше, чем перебор
