## Слои
экран-испытания = header-score → screen-dots → helper-panel → predict-before-run → previous-attempt-diff → rollback-after-failures
этап-разбор-машины = time-scale-screens → guided-pult-training → hint-ladder → predict-feedback
этап-голос-машины = prewritten-parts-note → hint-ladder → machine-mood → predict-before-run
этап-финал = final-table-to-scheme → personal-conclusion → endings-by-score
урок-эхо-узел = story-entry → pair-names → time-scale-screens → shift-clock → time-branch-master-online → time-branch-master-returned → bonus-call
тетрадный-блок = drakon-notes → scheme-legend → two-notes-compare → paste-in-sheet
учительский-слой = shared-text-file → teacher-canvas → teacher-hotkey → teacher-jump-menu → print-a4
пара-в-уроке = pair-roles → role-change-banner → pair-names → personal-conclusion

## Чего в образце нет, но нужно уроку 9 класса
- Нет явного повышения абстракции и терминов до уровня 9 класса: модель, признак, вероятность, данные.
- Нет заданий на перенос: обучить или оценить модель на своих примерах и сравнить с образцом.
- Нет критериев формирующего оценивания и метапредметной рефлексии.
- Нет дифференциации по сложности и ролей для групп больше двух.
- Нет обсуждения ограничений и этики речевых технологий.
