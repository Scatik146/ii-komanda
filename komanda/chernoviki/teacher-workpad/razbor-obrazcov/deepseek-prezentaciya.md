## Слои
- экран-гипотеза = prediction-slide → pair-worksheet → stage-timeline
- экран-секретный-тест = secret-test-choice → red-green-cards → hint-cards
- экран-конверт = envelope-terms → envelope-opening-slide → expected-answers
- экран-масштаб = dossier-numbers → complexity-ladder → bar-chart
- экран-смета = customer-cards-estimate → pair-worksheet → expected-answers
- этап-стенд = silent-teacher-rule → red-green-cards → hint-cards → challenge-card
- этап-рефлексия = exit-ticket → final-idea-slide → user-rule-slide
- урок = teacher-timing-table → stage-timeline → slide-controls → time-reserve
- оформление-урока = svg-illustration → short-headings → example-cards
- подготовка-урока = print-checklist → setup-checklist → no-rehearsal-safety

## Чего в образце нет, но нужно уроку 9 класса
- Нет сохранения состояния в localStorage с ключом-версией.
- Нет быстрого перехода Ctrl+Alt+M.
- Нет вынесения текстов урока в отдельный файл tekst.js.
- Нет использования шрифтов из lib/fonts.
- Нет канвы или вклейки для интерактивных заданий.
