# Задание 021: написать модуль словаря, этап 1 (прочитать, проверить, реестр, найти)

**Исполнитель:** DeepSeek · **Проверяет:** Марьям (Claude) или GLM, сливает учитель
**Статус:** не выдано — выдаётся после приёмки задания 020

## Цель
Программа, которая читает папку словаря, находит ошибки по таблице проверок и строит реестр. Это этап 1 из `forto-prolog/postanovka.md`.

## Прочитать
- `forto-prolog/postanovka.md` — разделы 4–9 и 11
- `pravila/FORTO-PROLOG-YAZYK.md` — грамматика (результат задания 020)
- `pravila/KOD-PO-FORTOVSKI.md` — как писать код
- `tools/ii.py` и `tools/test_ii.py` — образец стиля и тестов; готовые слова брать оттуда

## Можно менять
- `ii-py/slovar/slovar.py` — новый
- `ii-py/slovar/test_slovar.py` — новый
- `ii-py/slovar/obrazcy/` — новая папка: семь верных атомов и восемь испорченных (раздел 11 постановки)
- `tools/slovar-proverit.bat` — новый

## Сделать
1. `прочитать(путь)` — файл → пара: карточка (словарь Python «ключ → значение») и содержание (текст ниже блока).
2. `проверить(папка)` — список строк `код имя-файла: текст`. Проверки О01–О16 и О18 из раздела 8 постановки. О17 не делать: это этап 2.
3. Проверки описать **таблицей-данными** (код, слово-проверка, текст ошибки), а не цепочкой `if`. Одна проверка — одно слово.
4. `реестр(папка)` — файл `REESTR.md`: таблица «номер, имя, тип, истинность, проверено, статус, доступ, состав», по возрастанию номера. Последняя колонка — «утверждено: да / нет», вычисляется (истинность 1 и проверено «да»).
5. `найти(папка, слово)` — атомы, у которых слово встречается в `id`, `тема`, `описание` или `назначение`; без учёта регистра.
6. Запуск: `python ii-py/slovar/slovar.py proverit <папка>`, `… reestr <папка>`, `… najti <папка> <слово>`, ключ `--publichnyj` для проверки публичного словаря.
7. `tools/slovar-proverit.bat` — запускает проверку папки `slovar` и ждёт нажатия клавиши.

| Вход | Ровно что получится |
|---|---|
| папка с семью верными образцами | `словарь в порядке: 7 атомов`, код возврата 0 |
| каждый из восьми испорченных образцов раздела 11 | ровно одна строка с указанным там кодом, код возврата 1 |
| пустая папка | `словарь в порядке: 0 атомов`, код возврата 0 |
| папки нет | `нет папки <путь>`, код возврата 2 |
| файл не `.md` в папке словаря | пропускается молча |
| файл `REESTR.md` и `README.md` в папке словаря | пропускаются молча |
| `--publichnyj` и атом с доступом `приватное` | строка `О18 …: приватному атому не место в публичном словаре`, код возврата 1 |
| верный словарь, запуск `reestr` дважды | второй запуск не меняет файл |
| `najti` со словом, которого нет | `ничего не найдено`, код возврата 0 |

## Как писать код
- По правилу `pravila/KOD-PO-FORTOVSKI.md`: слово до 15 строк, вложенность не глубже двух, над словом `# слово: что делает`, один `return` последней строкой, данные отдельно.
- Только стандартная библиотека Python. Ничего не устанавливать.
- Имена слов — латиницей по-русски, как в `ii.py`: `prochitat`, `proverit`, `reestr`, `najti`.

## Нельзя
- Добавлять проверки, поля и коды сверх постановки; менять тексты ошибок.
- Исправлять файлы словаря: программа только сообщает.
- Трогать `tools/ii.py`, `pravila/`, постановку.
- Делать `собрать`, `вывести`, выгрузки: это следующие задания.

## Готово, когда
- `python ii-py/slovar/test_slovar.py` — все ✓; тест покрывает каждую строку таблицы выше;
- **код запущен:** в ответ вставлен вывод теста целиком, как его напечатал терминал; если терминала нет — так и написать и пометить вывод «предсказано»;
- в ответе: в начале — список «что изменено: слово — зачем»; файлы целиком, каждый в своём блоке, строкой выше — имя файла; что в задании было непонятно;
- в конце — «пополнение словаря»: `имя — слой — что делает — из каких слов собрано`;
- 2–5 входов, которые, по-твоему, ещё ломают результат, — в тест, разделом «Находки, ждут решения» (закрепляют текущее поведение, без починки).
