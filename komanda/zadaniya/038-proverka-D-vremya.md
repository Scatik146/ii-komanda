## Цель
Шаг Д опирается на перебор вариантов будущего. Нужен скрипт, который считает примеры и доказывает, что таблица Клини (min/max) здесь ошибается, а перебор - нет.

## Можно менять
- только новый файл `logika/kniga/proverka_D_vremya.py`

## Сделать
Значения: −1 нет, 0 не знаю, 1 да. НЕ x = −x, И = min, ИЛИ = max.
1. Слово `po_variantam(f, varianty)`: f считается в каждом варианте; во всех 1 → 1, во всех −1 → −1, иначе 0.
2. Морское сражение: варианты «будет» (p = 1) и «не будет» (p = −1).
   - по вариантам: p ИЛИ НЕ p = 1, p И НЕ p = −1, p = 0;
   - по таблице Клини при p = 0: p ИЛИ НЕ p = 0, p И НЕ p = 0. Это расхождение - assert.
3. `neotvratimo(sobytie, varianty, polnyj)`: во всех 1 и список полный → 1; во всех −1 и полный → −1; иначе 0. Пример свода: «пароль» во всех трёх планах урока, других планов нет → 1; тот же, но список неполный → 0.
4. `mozhet_byt(sobytie, varianty)`: хоть в одном 1 → 1; во всех −1 → −1; иначе 0.
5. Перебрать все функции от одной переменной из ИЛИ/И/НЕ глубины ≤ 2 и найти, где перебор вариантов и Клини расходятся; список расхождений вывести.

## Как писать код
- По `pravila/KOD-PO-FORTOVSKI.md`: маленькие слова с комментарием «слово: что делает», данные отдельно.

## Нельзя
- Менять другие файлы; писать не по-русски; подключать что-либо кроме стандартной библиотеки Python.

## Готово, когда
- `python3 logika/kniga/proverka_D_vremya.py` печатает «Д: все проверки прошли» и список расхождений из п. 5.
- В ответе: файл целиком; вывод запуска как напечатал терминал (нет терминала - так и написать, вывод пометить «предсказанный»); 2-5 входов, которые ещё могут сломать, - разделом «Находки, ждут решения».
