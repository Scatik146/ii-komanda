# Задание 042: сверить, как Клини называет третье значение

**Исполнитель:** Алиса · **Проверяет:** Claude (Марьям), решает учитель

## Цель
В Е.0 написано: «У Клини 0 - UNKNOWN, по-русски - „не знаю“». Это взято из пересказа (`forto-prolog/brusentsov.md`, таблица K3). По правилу 8 пересказ - это 0. Нужна сверка по подлиннику.

## Промпт для Алисы (вставить целиком)

Ты - эксперт по истории логики. Вопрос один, отвечай коротко.

Стивен Клини, книга «Introduction to Metamathematics» (1952), параграф 64 - трёхзначная логика (у Клини значения t, f, u).

Вопрос: как сам Клини называет и объясняет третье значение u? Какие слова он использует: «undefined», «unknown», «value immaterial» или другие?

Шаг 0. Сначала честно напиши одно из трёх:
- «читала подлинник» - знаю текст параграфа;
- «знаю по пересказу» - назови, по чьему;
- «не знаю».
Если не знаешь - так и напиши. Не придумывай цитату.

Формат ответа:
1. Шаг 0.
2. Как Клини называет u - его словами, по-английски, не длиннее двух предложений. Где: параграф, страница, если знаешь.
3. Одной строкой: можно ли честно написать «у Клини 0 - UNKNOWN, то есть „не знаю“»? Да / нет / с оговоркой (какой).
4. Одной строкой: что 0 значит в SQL (NULL, UNKNOWN) и связано ли это с Клини.

В конце напиши: КОНЕЦ ОТВЕТА 042.
