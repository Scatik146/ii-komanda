## Сделать

1. **Проверка чтения.** Первой строкой ответа три числа:
   - сколько допущений в разделе 2 постановки;
   - код последней проверки в разделе 8 постановки;
   - сколько образцов в самопроверке `graf.pl` по `site/experiments/prolog/README.md`.

### Часть А — файл атома

2. **Грамматика** файла атома в РБНФ (EBNF): файл, блок `атом`, строка поля, ключ, значение, список номеров, запись истинности по мирам, запись истории, строки `статус` и `версия`, пометка источника. У каждого правила — одна строка пояснения по-русски.
3. **Таблица значений:** для каждого ключа — образец значения и регулярное выражение или перечень допустимых слов. Ключи — из раздела 5 постановки с поправками:
   - убрать `допустимость` (Р5);
   - добавить `версия: ГГГГ-ММ-ДД | кто` (Р10);
   - `критичный`: `1`, `0`, `-1`, по умолчанию `0`; при `0001 = 1` значение `-1` — ошибка (Р11);
   - `истинность`: `NNNN = значение` через запятую, только миры, где атом используется; у не-утверждений `—` (Р1);
   - `доступ`: по Р12 его определяет папка. Поле это или вычисляемое значение — в «Что непонятно»;
   - пометки источника: добавить `[Д]` (Р26).

   Других ключей не добавлять.
4. **Таблица типов:** раздел 5 постановки плюс «правило-условность» (Р15) и «форма» (Р27). В живом словаре встречаются ещё типы `сборка`, `графа`, `тип атома`. Их в таблицу не вносить, а перечислить в «Что непонятно»: в решениях о них сказано «графа — не решено».
5. **Три верных примера** целиком:
   - `slovar/0001-realnost/0001-realnost.md` — дословно;
   - правило с блоком `конспект` в режиме знаний (`режим: знания`);
   - урок — страница HTML с составом.

   Содержание учебное, без людей.
6. **Три неверных примера** — по одному на ошибки `О02`, `О05`, `О11`. Под каждым — строка, которую должна напечатать проверка. Проверки О07 и О08 по Р5 уходят. Код для новой проверки «мир из записи истинности существует» не придумывать: место — в «Что непонятно».

| Вход | Ровно что получится |
|---|---|
| файл с двумя блоками `атом` | грамматика его не принимает |
| `состав: 0004,0005` (без пробела) | принимает; пробелы вокруг запятой необязательны |
| `состав:` (пусто) | не принимает; пустой список — слово `нет` |
| `статус: черновик` (одна часть) | не принимает |
| `id: 12-urok` | не принимает; номер — ровно четыре цифры |
| ключ `Тип:` с заглавной буквы | не принимает |
| строка истории без даты | не принимает |
| `истинность: 0002 = 1, 0001 = -1` | принимает |
| `истинность: 0002 = 2` | не принимает; значения `1`, `0`, `-1` |
| `критичный: да` | не принимает; значения `1`, `0`, `-1` |
| `версия: 2026-11-17` (без «кто») | не принимает |
| строка `допустимость: 0002` | не принимает; такого ключа нет |

### Часть Б — блоки ДРАКОН-листа

7. **Грамматика блока `дракон`** в РБНФ: заголовок, действие, `вопрос:` / `если:` с ветками `да:` и `нет:`, `выбор:` и `вариант:`, циклы, ввод и вывод, сдвиги. Всё — ровно как в шпаргалке и `текстовая_запись.md`.
8. **Грамматика блока `конспект`** в РБНФ, отдельно обычный режим и режим знаний: строки фактов и правил, переменные (`Х -> ?`), `пример:` и `контрпример:`, `запрос:`, `связка:`.
9. **Таблица «строка режима знаний → Пролог»:** как каждая строка становится фактом, правилом или запросом. Опора — `graf.pl` и `12_ГРАФ_и_Prolog.md`. Отдельной строкой: как `пример:` и `контрпример:` блока связаны с полями `пример` и `контрпример` атома.
10. **Где написанное правило расходится с разборщиком.** Шпаргалка, `текстовая_запись.md`, `graf.pl` и `parser.js` — все места, где они понимают строку по-разному. Не выбирать, какой прав.
11. **Предложение, а не правило: «или» и «не» в режиме знаний.** Сейчас режим знаний понимает только отношения двух участников, без «или» и «не». Предложи запись «или» и «не» и её перевод в Пролог: несколько правил, `\+`; можно опереться на преобразование Ллойда — Топора. Отдельно — как собрать такие правила обратно в одну строку текста. Раздел помечается «ПРЕДЛОЖЕНИЕ — не действует до решения учителя».
