# Задание 020: написать формальное описание языка «Форто-Пролог»

**Исполнитель:** GLM (запасной — DeepSeek) · **Проверяет:** Марьям (Claude), сливает учитель
**Статус:** не выдано — ждёт слова учителя

## Цель
Одна страница, по которой программа однозначно читает файл атома: грамматика, значения полей, три верных примера и три неверных. Это этап 0 из `forto-prolog/postanovka.md`.

## Прочитать
- `forto-prolog/postanovka.md` — целиком; разделы 4, 5, 6, 8 — главное
- `pravila/FORTO-PROLOG.md` — для смысла; при расхождении с постановкой — не выбирать самому, а записать в «Что непонятно»

Исполнителю без доступа к репозиторию учитель прикладывает оба файла текстом.

## Можно менять
- `pravila/FORTO-PROLOG-YAZYK.md` — новый файл; больше ничего

## Сделать
1. **Проверка чтения.** Первой строкой ответа: сколько допущений в разделе 2 постановки и код последней проверки в разделе 8.
2. **Грамматика** файла атома в виде РБНФ (EBNF): файл, блок `атом`, строка поля, ключ, значение, список номеров, запись истории, строка статуса, пометка источника. Каждое правило грамматики — с одной строкой пояснения по-русски.
3. **Таблица значений:** для каждого ключа — образец значения и регулярное выражение или перечень допустимых слов. Ровно ключи раздела 5 постановки, ни одного сверх.
4. **Таблица типов:** перенести из раздела 5 постановки без изменений.
5. **Три верных примера** целиком: `0001-realnyj-mir.md`, `0005-pravilo-…​.md` (правило с блоком `конспект`, `режим: знания`), `0010-urok-…​.md` (страница HTML с составом). Содержание учебное, без людей.
6. **Три неверных примера** — по одному на ошибки `О02`, `О05`, `О11`; под каждым — строка, которую должна напечатать проверка.
7. **Что непонятно:** места постановки, которые читаются двояко. Не решать их самому.

| Вход | Ровно что получится |
|---|---|
| файл с двумя блоками `атом` | грамматика его не принимает |
| `состав: 0004,0005` (без пробела) | принимает; пробелы вокруг запятой необязательны |
| `состав:` (пусто) | не принимает; пустой список — слово `нет` |
| `статус: черновик` (одна часть) | не принимает |
| `id: 12-urok` | не принимает; номер — ровно четыре цифры |
| ключ `Тип:` с заглавной буквы | не принимает |
| строка истории без даты | не принимает |

## Нельзя
- Добавлять поля, типы и коды ошибок, которых нет в постановке.
- Менять `pravila/FORTO-PROLOG.md` и постановку.
- Писать текст длиннее двух страниц: страница грамматики и таблиц, страница примеров.

## Готово, когда
- по грамматике можно вручную разобрать все три верных примера, и ни один неверный её не проходит;
- каждая строка таблицы «вход → результат» выше выполняется;
- в ответе: проверка чтения, файл целиком одним блоком (строкой выше — имя файла), раздел «Что непонятно»;
- ничего не выдумано: всё, чего нет в постановке, вынесено в «Что непонятно».
