## 1. Проверка чтения

1. **Г.1.** `(1 < 3) < 2` — `True`: сначала сравнение даёт `True` (это 1), потом `1 < 2` — истина. А `1 < 3 < 2` — `False`: Python разворачивает цепочку как `1 < 3 and 3 < 2`, а `3 < 2` — ложь. Разница именно в скобках: сравнивается результат сравнения либо обе пары сразу.
2. **Г.3.** Ответ задачи — **220** (мой перебор всех 1000 троек: 220, распределение по суммам совпало с таблицей). В контрпримере «один знак не туда» (из `x − z ≥ −y` получено `x + y ≤ z`, то есть ¬A вместо B) выражение становится тождественно истинным — ответ **1000**. Оба числа подтвердились перебором.
3. **Г.5.** Ответ демоверсии 2021 — **18**. A = 36 не годится: при x = 18 левые условия выполняются, а Д36 = 0, формула ложна. A = 54 не годится по той же причине (x = 18: Д54 = 0). Суть: A должен *делить* 18, а не делиться на 6 и 9; перебор подтверждает ровно {1, 2, 3, 6, 9, 18}.
4. **Г.7.** `26 | 13` = `11010 | 01101` = `11111` = **31**. Ответ задачи — **2** (перебор даёт первые подходящие 2, 3, 6, 7, 10 — как в книге).
5. **Д.3.** Левый край треугольника для x → y: **1, 0, 1, 1**. Многочлен: **1 ⊕ x ⊕ xy** (мономы: 1, y=0, x, xy).
6. **Е.3.** **S = C ⊕ p, P = g ∨ (C ∧ p)**, где p = A ⊕ B, g = A ∧ B. Пять элементов: два ⊕, два И, один ИЛИ. Сверено на всех 8 наборах.
7. **Е.4.** Порядок 00, 01, 11, 10 — код Грея: любые соседние столбцы (и крайние 10 ↔ 00) отличаются ровно одной буквой, поэтому «склейку» (…∧z) ∨ (…∧¬z) можно делать и через край — карта «сворачивается в трубку».
