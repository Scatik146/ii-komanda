## 3. Ответ по ★

Все **8 законов со ★ действительно ломаются** — подстановки:

| Закон | Подстановка | Слева | Справа |
|---|---|---|---|
| x ∨ ¬x = 1 | x = 0 | 0 ∨ 0 = 0 | 1 |
| x ∧ ¬x = 0 | x = 1 | 1 ∧ (−1) = −1 | 0 |
| (x ∧ y) ∨ (x ∧ ¬y) = x | x = 1, y = 0 | 0 ∨ 0 = 0 | 1 |
| (x ∨ y) ∧ (x ∨ ¬y) = x | x = −1, y = 0 | 0 ∧ 0 = 0 | −1 |
| x ∨ (¬x ∧ y) = x ∨ y | x = 0, y = 1 | 0 ∨ 0 = 0 | 1 |
| x ∧ (¬x ∨ y) = x ∧ y | x = 0, y = −1 | 0 ∧ 0 = 0 | −1 |
| x → x = 1 | x = 0 | 0 → 0 = 0 | 1 |
| (x ∧ (x → y)) → y = 1 | x = 1, y = 0 | 0 → 0 = 0 | 1 |

Но **есть три закона без ★, которые тоже ломаются**:

| Закон (Б.1) | Подстановка | Слева | Справа |
|---|---|---|---|
| x ∧ 0 = 0 (группа 1) | x = −1 | −1 ∧ 0 = −1 | 0 |
| x ∨ 0 = x (группа 1) | x = −1 | −1 ∨ 0 = 0 | −1 |
| 0 → x = 1 (группа 7) | x = −1 | 0 → (−1) = 0 | 1 |

Причина одна: 0 («не знаю») перестаёт быть нейтральным для И и ИЛИ. Все остальные законы без ★ (идемпотентность, двойное отрицание, переместительный, сочетательный, оба распределительных, де Моргана, поглощение, контрапозиция, отрицание импликации, 1 → x = x, экспортация, обе эквивалентности) я проверил на всех 27 наборах тритов — держатся. Значит: **со значками книга не совпадает — их не хватает**, и вывод Б.3 «это ровно те, что со значком ★» надо смягчить («ломаются и три закона с константой ноль»).
