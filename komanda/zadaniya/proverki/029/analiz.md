## Алиса (`otvet-alisa.md`)

Проверка чтения: 5 из 5 верно по ключу. Первая строка ответа («Мой первый скрипт ошибся…») — мусор из её черновика, на суть не влияет.

### Ответ по ★

8 законов со ★ ломаются — согласна с эталоном. Но в двух подстановках из восьми ошибка: правую часть «0» она читает как «не знаю». Пример: x ∧ ¬x = 0 при x = 1 даёт −1 = −1, то есть закон держится. Ломается он при x = 0: слева 0, справа −1.

Три «новых» закона без ★ (x ∧ 0 = 0, x ∨ 0 = x, 0 → x = 1) — **Н**. Причина та же: константу 0 из закона («ложь») она подставила как трит 0 («не знаю»). Если 0 → −1, все три держатся на всех тритах. Проверено скриптом: «0 = не знаю» — ломаются; «0 = нет» — держатся.

Корень ошибки — в нашем промпте: мы написали «0 не знаю», но не сказали, во что переходит константа 0 из закона. Это и **риск для части 2**: ученик сделает ту же ошибку. → вопрос учителю (Р).
