## Сделать

### Шаг 0. Сначала - только доклад «прочитал ли целиком»

На каждую часть ответ - только:
- «часть N: прочитана целиком / частично»;
- последняя строка, которую видишь, дословно. Если часть дочитана, это «КОНЕЦ ЧАСТИ N ИЗ 3. Куски a-b.» Не видишь её - напиши, на каком куске оборвалось.

Когда все три части прочитаны - одна строка «все 3 части прочитаны, кусков 28» - и **ждать**, пока учитель не напишет «продолжай».

### Шаг 1. Ответ по частям

Учитель пишет «часть 1» - ответ только по кускам этой части. В конце - «КОНЕЦ ОТВЕТА ПО ЧАСТИ 1». Ждать. Так же части 2 и 3.

По каждому куску - две строки:
1. **Снято ли замечание:** да / частично / нет. Если не «да» - чего не хватает, одной фразой.
2. **Новое противоречие:** нет - или есть: с чем (номер правила или куска), цитата, в чём противоречие.

Замечание - по тексту, с цитатой. «Можно лучше» без противоречия - не нужно. Стиль автора (короткие фразы, «я», примеры из школы) - не править: это голос книги.

### Шаг 2. Итог, по команде «итог»
- Противоречия **между** кусками разных частей (например, кусок из части 1 и кусок из части 3).
- Замечания сводки 041, которые, по-твоему, сняты только наполовину, - списком.
- Не больше трёх самых важных находок на весь шаг Е.
