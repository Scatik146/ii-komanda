# Команда ИИ: вход для помощников

**Начинать с `SOSTOYANIE.md`** (одна страница), день — с брифинга (`BRIFING.md`). Если Claude недоступен — `BEZ_CLAUDE.md` (роли, цикл задачи, промпты). Задания помощникам — по шаблону ii-komanda `komanda/zadaniya/SHABLON.md`.

Этот файл — общая память проекта ДРАКОН-ГРАФ для всех ИИ, которые над ним работают: Claude, Qwen, GLM, DeepSeek, Алиса, YandexGPT. Здесь собрано то, что раньше хранилось только в памяти Claude: решения, договорённости, открытые вопросы. Перед работой прочитайте его целиком.

## 2. Правила работы (для всех помощников)

- Всё по-русски: тексты, интерфейсы, сообщения коммитов.
- Перед правкой прочитать `CLAUDE.md` и README нужного репозитория. Они главнее этого файла.
- Никаких CDN в материалах уроков: всё по относительным путям внутри сайта. Исключение — формулы MathJax в генераторе на GitHub Pages.
- Каждую схему и каждый конспект проверять программой:
  - `node tools/konspekt.mjs --scan файл --class N` (конспект);
  - `node tools/drakon-shema.mjs --scan файл` (дракон-схема);
  - и смотреть рисунок в браузере.
- Код (любой язык, кроме Prolog) — «по-фортовски»: ii-komanda `pravila/KOD-PO-FORTOVSKI.md`; Prolog — «по-прологовски» (как описать): ii-komanda `pravila/KOD-PO-PROLOGOVSKI.md`, и «по-графовски» (как нарисовать): `pravila/KOD-PO-GRAFOVSKI.md`.
- Не придумывать синтаксис языка: справочники — `docs/graf/`, навык — `navyk/drakon-graf-konspekt.md`, канон ДРАКОНа — `docs/research/08_ДРАКОН_язык_разбор.md`.
- Изменения — через ветку и Pull Request; учитель смотрит и сливает. Прямо в `main` пишет только Claude по прямой просьбе учителя.
- Каждый новый источник записывать в `docs/литература.md`, каждое решение — в раздел 4 этого файла.
- Все помощники читают `SOSTOYANIE.md` перед работой и после задачи дописывают итог строкой в `BRIFING.md` под датой. **`SOSTOYANIE.md` с 14.11 ведёт координатор:** составляет Алиса, вставляет учитель; чаты туда не пишут — последней строкой ответа присылают сводку «Для Алисы: …».
