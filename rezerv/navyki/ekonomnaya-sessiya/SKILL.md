# Экономная сессия

Навык команды: работает в любом чате и любом проекте. Учитель платит лимитом. Дорого стоят: чтение больших файлов и книг, скриншоты, повторные запуски браузера, длинная история разговора.

**Правило места:** все рабочие файлы навыка и состояние — в ii-komanda. Из других репозиториев навык читает только то, на что сослался в задаче, и только по чтению.

## Проекты: состояние и правила

Правила каждого проекта — копия его `CLAUDE.md` в ii-komanda `pravila/проекты/<репозиторий>-CLAUDE.md`. В шапке файла указаны источник, коммит и дата копии. **Копию читать, только если репозиторий проекта в этой сессии не клонируется;** если клонируется — подлинник придёт сам после `register_repo_root`, а две копии в истории — двойная плата на каждом запросе. Перед работой сверить коммит источника (`git ls-remote <url> HEAD`): если не совпадает — сказать учителю «правила в ii-komanda старше источника, обновить?» и ждать ответа.

## Начало
0. Определить проект по таблице выше.
1. Склонировать только ii-komanda (`--depth 1`). Если задача требует чтения другого репозитория — клонировать его `--depth 1` только для чтения.
2. Прочитать **только** верхний раздел файла состояния своего проекта (`grep -n '^## '`, затем `sed -n` этого раздела: файл давно длиннее страницы) и файл правил. Журналы, разборы и документы — только нужный раздел, через grep.
3. Сформулировать **одну задачу сессии** и критерий «готово». Новая большая тема — в следующую сессию, в «Следующие шаги».

## Во время работы
- Читать файлы кусками (grep, sed -n), не целиком. Не выводить большие файлы и логи в разговор.
- **Скриншоты сама не смотрю** (учитель 25.11 03:17, задание 047): обход экранов и снимки — программа, мне — код выхода; глазами — учитель по сводной картинке при приёмке. Учителя нет — один скриншот после последней правки, масштаб 0.5, нужная область.
- Чтение книг, статей, чужих репозиториев, рутинный код по готовому описанию, тексты для детей — **делегировать**: задание по шаблону `komanda/zadaniya/SHABLON.md` (уроки — файлом `komanda/zadaniya/NNN-имя.md`).
- Код (любой язык, кроме Prolog) — «по-фортовски»: ii-komanda `pravila/KOD-PO-FORTOVSKI.md`. Остальные стили — навык `tri-stilya-koda`.
- Распределение по помощникам — `komanda/README.md`.
- Черновики уроков — `komanda/chernoviki/<репозиторий>/`, не в репозиторий урока.
- Короткие ответы учителю: итог и вопросы, без пересказа шагов.
- **Меньше вызовов** (замер 25.11: 172 запроса за сессию, 63 % расхода — повторное чтение всего контекста на каждом запросе): склеивать команды в один вызов (проверка + тест + коммит), не дробить чтение на мелкие куски без нужды.
- **Проверка урока и приёмка** — по навыку `teacher-workpad-sajt` (раздел проверки), здесь не дублировать (Л28).
- **Большие файлы — `Edit` по частям**, не `Write` целиком: каждая копия остаётся в разговоре и перечитывается на каждом запросе (урок 11 10 кл.: приложение переписано целиком трижды).
- **Навыки и большие файлы — по моменту, не в начале:** загруженное в начале оплачивается на каждом запросе сессии.
- **Урок по чату Алисы — два чата:** со-анализ → `sverka.md`; сборка — в новом чате только по сверке (вставка `komanda/vstavka/claude/05-sborka-v7-5-B.md`).
- **Одна задача — один чат.** Учитель сказал «Принято» — предложить закрыть чат и мелкие вопросы вести в новом (длинная история дорожает с каждым ходом).

## Конец (обязательно)
1. Обновить файл состояния проекта в ii-komanda (не длиннее страницы): свой блок сверху, 2–3 строки — что сделано, следующий шаг. Сверху не больше трёх блоков сессий; старые — в `komanda/arhiv/SOSTOYANIE-arhiv.md` (решение 25.11). В чате брифинга SOSTOYANIE не писать — там сводка «Для Алисы». Копии списков в проект Claude (`Разработано`, `Доработки`) — здесь, один раз за задачу.
2. Решения учителя — строкой в `komanda/README.md` § 4; открытые вопросы — § 5.
3. Если менялись навыки — копии в ii-komanda `rezerv/navyki/` и предложение обновить навык.
4. **Только если** в этой сессии менялись навыки или память (иначе пропустить) — обновить приватный репозиторий `Scatik146/memory_maryam_ai` (резервная копия): навыки — `navyki/<имя>/SKILL.md`, общая память — `pamyat/obshchaya/`, память проекта — `pamyat/proekt-<название-латиницей>/`. Без паролей, ключей и данных учеников. Коммит «Память: …» или «Навыки: …».
5. Всё отправить в GitHub; в ответе — что сделано и что ждёт решения.
