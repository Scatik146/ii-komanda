# Сайт teacher-workpad

Сайт уроков учителя: `Scatik146/teacher-workpad` (GitHub Pages; запасной вариант — школьная сетевая папка без интернета). Всё по-русски: тексты, интерфейсы, коммиты.

## Начало работы
1. `add_repo` (owner `Scatik146`, repo `teacher-workpad`, access `push`), затем `git clone --depth 1 https://github.com/Scatik146/teacher-workpad /home/claude/teacher-workpad`.
2. Прочитать `CLAUDE.md` репозитория — там действующие правила. Он главнее этого навыка.
3. Для помощников ИИ — ii-komanda `komanda/VHOD-UROKI.md`; копии навыков — ii-komanda `rezerv/navyki/` (при правке навыка обновить копию). Журнал решений по ДРАКОН-ГРАФ и дракон-схемам — `Scatik146/ii-komanda`, `komanda/README.md`.

## Правила приложений
- Папка `<класс>-klass/<имя>/` (для нескольких предметов — `obshchie/<имя>/`), приложение — `index.html`, рядом другие файлы.
- Скрытое меню **Ctrl+Alt+M**: переход по экранам с заполнением данных по умолчанию; туда же служебное (часы, печать). На сайте и в материалах для учеников не упоминать.
- Прогресс — `localStorage` в try/catch; кнопка «Новая смена / начать заново» для следующей пары.
- Никаких CDN: всё по относительным путям внутри сайта (`../../lib/…`).
- Тексты урока — в общем `tekst.js`, его читают и игра, и канва учителя.
- Материалы учителя — HTML в папке урока в стиле `*/kanva.html` (.pptx/.docx переводить в HTML; Claude Docs у учителя не открывается).
- Варианты ответов перемешивать (верный не всегда первый); в парах — роли «за пультом / штурман».
- Конспекты и схемы — навыки `graficheskij-konspekt` и `drakon-shema`.
- Код приложений — «по-фортовски» (ii-komanda `pravila/KOD-PO-FORTOVSKI.md`): маленькие слова с комментарием «слово: что делает», слои снизу вверх, данные отдельно; в конце работы — «пополнение словаря».

## Каталог и списки
- Урок — объект в `LESSONS` в `lessons.js` (`where:[{s:'iiib'|'inf'|'mat'|'trud', g:класс}]`, title, topic, about, format, path, teacher:[{label, href, kind:'slides'|'print'|'guide'|'tool'}]; `ready:false` — скрыт) и строка в таблице `README.md`.
- После изменений обновить `RAZRABOTANO.md` и `DORABOTKI.md`. В проект Claude «Разработка уроков» (`claude/Разработано teacher-workpad.md`, `claude/Доработки teacher-workpad.md`) записывать их **один раз — в конце задачи** (решение учителя 25.11, экономия лимита): `project_read` обоих, затем `project_write` с `local_path`. Правки между — только в файлах репозитория.

## Проверка перед отправкой
- **Сначала — одна команда проверки урока, один раз после последней правки:** `python3 -I tools/proverka-vsyo.py <папка урока> --kartinka svodka.png` (страницы через `proverka-uroka.py` — слайды, листы PDF, первый экран, консоль; ДРАКОН-листы, схемы, конспекты, стиль кода, тесты ДРАКОН при правке библиотеки, git). Отчёт — в ответ учителю; сводную картинку смотреть целиком (пустые рамки и обрезанные схемы программа не видит).
- **Проход приложения путём пользователя — учитель при приёмке** (дешевле человеком, учитель 25.11 02:55): ему — список экранов, действий и что должно получиться. Учителя нет — пройти самой в headless Chrome (`/usr/bin/google-chrome` + Python playwright, file://, 1366×768, все ветки: обычная, ускоренная, ранний финал).
- Синтаксис скрипта: вырезать `<script>` и `node --check`.
- Длины реплик для детей проверять скриптом, если есть лимиты.
