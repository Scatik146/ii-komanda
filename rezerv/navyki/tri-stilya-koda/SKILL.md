# Три стиля кода и ДРАКОН-лист

Навык команды. Решение учителя 15.11.2026 (журнал ii-komanda `komanda/README.md` § 4). Правила — ii-komanda `pravila/`: `KOD-PO-FORTOVSKI.md`, `KOD-PO-PROLOGOVSKI.md`, `KOD-PO-GRAFOVSKI.md`. Помощникам без навыков (GLM, DeepSeek, Алиса) — текст целиком: `pravila/TRI-STILYA-ODNIM-TEKSTOM.md`.

**Правило места:** рабочие файлы и инструменты проверки — в ii-komanda (`tools/`). Стенды Prolog и Forth — в drakon-graf (`site/experiments/`), навык читает их только по чтению.

**До кода — найти готовое:** прочитать teacher-workpad `lib/slova/SLOVA.md` (≈ 65 строк) и взять готовое слово, а не писать заново. Вынести общее, кандидаты и банк фактов — навык `slovar-forto-prologa`, в конце сборки урока.

## Какой стиль когда

| Что пишешь | Стиль | Вопрос стиля |
|---|---|---|
| действия: JS, Python, Forth, служебный код вокруг Prolog | по-фортовски | как разложить |
| знания и данные: факты и правила Prolog; разметка HTML; правила CSS; данные JSON; тексты Markdown | по-прологовски | как описать |
| любую программу целиком | по-графовски | как нарисовать |

Одна программа обычно требует всех трёх: действия раскладываем, знания описываем, всё вместе рисуем ДРАКОН-листом.

## По-фортовски — как разложить
- Программа — словарь маленьких слов. Одно слово — одно действие, до 15 строк (потолок, не цель), вложенность не глубже 2.
- Имена — из словаря предмета; над каждой функцией строка по-русски «слово: что делает».
- Слои снизу вверх: верхнее слово читается как фраза.
- Данные отдельно от действий, структура данных описана явно.
- Один вход, один выход: ровно один `return`, последней строкой; без однострочников и цепочек тернарных операторов.
- При переделке поведение не меняется: сначала «вход → результат», потом переделка.
- Forth: стандартные слова заглавными (`DUP`); русские имена слов работают; ожидаемый результат теста — по реальному выводу движка.

## По-прологовски — как описать
- Описывай, что верно, а не как вычислить: факты и правила отдельно от поиска.
- В правиле не больше 3 условий; больше — выдели промежуточное отношение.
- Имена отношений — русские, из словаря предмета.
- У каждого отношения есть «пример:» (должно выводиться) и «контрпример:» (не должно).
- В знаниях нет cut (`!`), `->`, assert/retract и побочных эффектов.
- Нерекурсивное правило — первым; ответ собирать `findall`; `\+` — только на связанных переменных.
- HTML говорит, что это, а не как выглядит; без `style="…"` и `onclick="…"`. CSS — «селектор → свойства», цвета и размеры переменными, без `!important`.
- JSON — структура полей и связей: имена из словаря предмета; связь — поле-ссылка, а не вложенная копия; действий и вычислений нет.
- Markdown говорит, что это (заголовок, список, блок кода); ограды закрыты.

## По-графовски — как нарисовать
- Факт — связь с подписью: `родитель(иван, петр).` = связь Иван -> Пётр: родитель.
- Правило — строка «…, если … и …» и ДРАКОН-схема «как проверяется».
- Запрос — запоминатель с пустым ответом (`кто -> ?`).
- Туда и обратно: по коду рисуется ДРАКОН-лист, по листу восстанавливается код. Чего нет на листе — того нет в коде, и наоборот.

## ДРАКОН-лист
Obычный Markdown-файл рядом с кодом. По порядку:
- блок ```` ```дракон ```` — порядок действий (спецификация записи: ii-komanda `pravila/` или drakon-graf `docs/drakon/текстовая_запись.md`);
- блок ```` ```конспект ```` — данные, факты и правила на языке ДРАКОН-ГРАФ;
- тест — строки `пример:` и `контрпример:`.
Образец — ii-komanda `pravila/primery/drakon-list-evklid.md`. Текст в иконах пиши на целевом языке.

## Что сдавать в конце работы

## Проверка (из клона ii-komanda)
- По-фортовски (JS, Python): `node tools/stil-fort.cjs <файл>`; код выхода 1 — замечания есть.
- ДРАКОН-лист: `node tools/drakon-list.mjs лист.md` — все блоки без ошибок; `--strogo` — отсутствие блока или теста считается ошибкой; `--kod python` (также `kumir`, `c`, `1c`) печатает код по блокам `дракон`, `-o файл` сохраняет.
- Тест: запусти код на строках `пример:` и `контрпример:` — пример получается, контрпример нет.
- Prolog: стенд в drakon-graf `site/experiments/prolog/`; свой `.pl` — `python3 tools/prolog-zapusk.py программа.pl --zapros "запрос"` (нужны Chrome и Python playwright; `--json` для скриптов). Forth: `node site/experiments/forth/run-node.cjs` в drakon-graf.
- Проверщика по-прологовски (`stil-prolog`) пока нет: проверку «без `!`, не больше трёх условий, есть пример и контрпример» делать вручную до его появления.

## Чего пока нет (не обещать)
- Страницы, которая рисует оба блока листа вместе (редактор «Живой конспект» — пока ТЗ).
- Автоматического перевода «код → ДРАКОН-схема» и «правило Prolog → ДРАКОН-схема»: рисуем руками.
- Проверщика по-прологовски (`stil-prolog`).

YAML и Shell — вне навыка: менять только по отдельному заданию и после проверки.

Не знаешь или не нашёл в файлах — пиши «не знаю, надо проверить». Про реальный мир (оборудование, сеть, группы) сначала спроси учителя.
