# ii-komanda — команда ИИ-помощников учителя

Общая часть для всех проектов и для разработки уроков: роли, промпты для вставки, шаблоны заданий, автоматизация (GitHub Actions, API моделей), сайт команды. В самих проектах (`drakon-graf`, `teacher-workpad`, …) остаются только их состояние, задания и журнал.

Репозиторий открытый. Резерв: GitHub (основной) → SourceCraft (зеркало) → Huawei Cloud (третья копия) + холодный архив.

## Состав (по мере наполнения)

| Папка | Что там |
|---|---|
| `istochniki/` | Архив: как было до репозитория (алгоритмы уроков, промпты) — не править |
| `roli/` | Роли и промпты для вставки — одна версия на роль |
| `uroki/` | Единый алгоритм разработки урока |
| `proekty/` | Цикл задачи для проектов (код, библиотеки) |
| `shablony/` | Шаблоны заданий, заявок, отчётов |
| `tools/` | Общий скрипт «ИИ-исполнитель», проверки |

## Правила
- Записи состояния и журналов ведёт только **координатор** (Алиса через учителя или workflow); помощники сдают итог одной строкой.
- Статус задания — строкой в самом файле задания.
- Архитектурные вопросы без Claude решает **консилиум** (китайская, американская, русская модели), последнее слово — учитель.
- Промпты пишем модель-агностично: вставляются в любой ИИ, ссылки — прямые (raw).
