# Задача учителю: проверить ключи API (14.11.2026)

Отдельная задача, 15–20 минут. Нужна к шагу 3 чата 11 (команда `ii.py klyuchi`). Устройство скрипта — `USTROJSTVO.md`.

**Готово, когда:** известно по каждой строке таблицы — ключ есть / нет, деньги есть / нет; ключи лежат в файле на ноутбуке.

| Поставщик | Где смотреть | Что нужно | Итог (заполнить) |
|---|---|---|---|
| Яндекс (Alice AI, YandexART) | aistudio.yandex.ru → API-ключи; раздел оплаты | ключ, идентификатор каталога (folder ID), остаток гранта | |
| DeepSeek | platform.deepseek.com → API keys; баланс | ключ, деньги на балансе | |
| GLM | консоль поставщика | ключ, способ оплаты | |
| Qwen | консоль поставщика | ключ, способ оплаты | |

## Шаги

1. Яндекс — первым: с ним одним скрипт уже может работать (запасной путь «все роли через Яндекс», `USTROJSTVO.md` § 5).
2. DeepSeek: посмотреть, есть ли ключ и баланс; оплата — по возможности.
3. GLM и Qwen: только выяснить, можно ли получить ключ и чем платить. Не получится — не страшно.
4. Создать файл `.ii-komanda.env` в домашней папке (`C:\Users\<имя>\`), по строке на значение:

```
YANDEX_API_KEY=…
YANDEX_FOLDER_ID=…
DEEPSEEK_API_KEY=…
GLM_API_KEY=…
QWEN_API_KEY=…
```

Строки без ключа — не писать.

5. Когда чат 11 сделает команду: `python tools/ii.py klyuchi` — и прислать таблицу «работает / нет ключа / нет денег / ошибка сети».

## Нельзя

Вставлять ключи в чаты помощников, в репозитории, в файлы заданий. В таблицу выше — только «есть / нет», не сам ключ.
