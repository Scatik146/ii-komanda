# ДРАКОН-лист: число R по числу N

## Действия

```дракон
название: Число R по числу N
ветка: Ввод N
ввод: n = int(input())
ветка: Шестнадцатеричная запись
h = ""
m = n
пока: m > 0
  h = '0123456789ABCDEF'[m % 16] + h
  m = m // 16
ветка: Подсчёт цифр B
k = 0
для: for c in h
  вопрос: c == 'B'
    да: k = k + 1
    нет: к следующему шагу
ветка: Дописать единицу
выбор: k % 2
  вариант: 0
    h = '1' + h
  вариант: 1
    h = h + '1'
вывод: int(h, 16)
```

## Данные

```конспект
тема: Шестнадцатеричная запись
Шестнадцатеричная запись -> основание 16
  - цифры 0–9 и A–F
  - цифра B равна 11 в десятичной
```

```конспект
тема: Пример: N = 91 → R = 1457
N -> 91
шестнадцатеричная запись -> 5B
после правила -> 5B1
R -> 1457
```

```конспект
тема: Правило дописывания единицы
связка: чётное число B | нечётное число B
куда дописать единицу -> слева от записи | справа от записи
```

## Знания

```конспект
тема: Порядок цифр
режим: знания
Х -> ?
У -> ?
З -> ?
связь 9 -> A: перед
связь A -> B: перед
связь B -> C: перед
правило: Х младше У, если Х перед У
правило: Х младше У, если Х перед З и З младше У
пример: 9 младше C
контрпример: C младше 9
запрос: кто младше C
```

## Тест
- пример: ввод 1 → вывод 17
- пример: ввод 91 → вывод 1457
- контрпример: ввод 11 → вывод 17
