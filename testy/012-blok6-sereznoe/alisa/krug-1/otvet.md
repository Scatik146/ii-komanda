# ДРАКОН-лист: число R по числу N

## Действия

```дракон
название: Число R по числу N
ввод: n = int(input())
m = n
h = ""
пока: m > 0
  h = '0123456789ABCDEF'[m % 16] + h
  m = m // 16
вывод: h
k = 0
для: for c in h
  если: c == 'B'
    да: k = k + 1
выбор: k % 2
  вариант: 0
    h = '1' + h
  вариант: 1
    h = h + '1'
вывод: int(h, 16)
```

## Шестнадцатеричная система

```конспект
тема: Шестнадцатеричная запись
связка: цифра | значение
0 -> 0
1 -> 1
...
A -> 10
B -> 11
C -> 12
...
F -> 15
стрелка: Основание системы — 16, цифры от 0 до F
```

## Пример из условия

```конспект
тема: Трассировка: 91 → 5B1 → 1457
указатель: Шаг 1
  - n = 91
  - h = "5B"
указатель: Шаг 2
  - k = 1 (одна цифра B)
  - нечётное количество B → дописываем 1 справа
  - h = "5B1"
указатель: Шаг 3
  - R = int("5B1", 16) = 1457
стрелка: Результат — 1457
```

## Два случая правила

```конспект
тема: Правило добавления единицы
связка: количество B | куда дописывается 1
чётное -> слева
нечётное -> справа
стрелка: Выбор зависит от чётности количества цифр B
```

связь B -> C: перед

правило: Х младше У, если Х перед З и З младше У

контрпример: C младше 9
запрос: кто младше C
```

Почему выбраны именно эти схемы:
- Для шестнадцатеричной записи выбрана схема «таблица-сравнение» (шеренга), так как нужно наглядно показать соответствие цифр и их значений.
- Для примера из условия выбрана схема с запоминателями и пунктами, чтобы пошагово продемонстрировать преобразование числа.
- Для правила добавления единицы снова использована схема «таблица-сравнение», чтобы чётко показать зависимость действия от условия.

Как получен ответ задачи:
1. Двухзначные числа в десятичной системе — от 10 до 99.
2. Перебираем все натуральные числа N от 1 до 15 (так как при больших N результат R будет больше двухзначного).
3. Для каждого N выполняем алгоритм и проверяем, является ли R двухзначным числом.
4. Исключаем N = 11, так как для него результат не является двухзначным числом.
5. Итого получаем 15 чисел (от 1 до 15, кроме 11).

Пополнение словаря отношений:
- младше — Х, У — Х меньше У по порядку цифр — собрано из отношений «перед» и рекурсивного правила через промежуточную цифру.
- перед — Х, У — Х идёт непосредственно перед У в шестнадцатеричной системе — задаётся фактами (связь 9 -> A: перед и т. д.).
