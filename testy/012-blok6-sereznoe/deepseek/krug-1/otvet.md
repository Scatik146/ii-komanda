# ДРАКОН-лист: число R по числу N

## Действия

```дракон
название: Число R по числу N
ветка: Ввод
  ввод: n = int(input())
ветка: Шестнадцатеричная запись
  m = n
  h = ''
  пока: m > 0
    h = '0123456789ABCDEF'[m % 16] + h
    m = m // 16
ветка: Подсчёт цифр B
  k = 0
  для: for c in h
    вопрос: c == 'B'
      да:
        k = k + 1
      нет:
        k = k
ветка: Дописать единицу
  выбор: k % 2
    вариант: 0
      h = '1' + h
    вариант: 1
      h = h + '1'
  вывод: int(h, 16)
```

## Данные

```конспект
тема: Шестнадцатеричная запись
Основание -> 16
Цифры -> 0-9, A-F
Цифра B -> 11
```

```конспект
тема: Пример из условия
- 91 в шестнадцатеричной записи: 5B
- цифра B одна, количество нечётное
- дописываем 1 справа: 5B1
- 5B1 в десятичной: 1457
```

```конспект
тема: Два случая правила
связка: Чётное количество B | Нечётное количество B
Куда дописать 1 -> слева | справа
```

## Знания

```конспект
тема: Порядок цифр
режим: знания
Х -> ?
У -> ?
З -> ?
связь 9 -> A: перед
связь A -> B: перед
связь B -> C: перед
правило: Х младше У, если Х перед У
правило: Х младше З, если Х перед У и У младше З
пример: 9 младше C
контрпример: C младше 9
запрос: кто младше C
```

## Тест

- пример: ввод 91 → вывод 1457
- пример: ввод 1 → вывод 17
- пример: ввод 11 → вывод 177
- контрпример: ввод 91 → вывод 1456

otvet.txt
```text
14
```

Почему схемы:
- «Шестнадцатеричная запись» — `указатель -> ответ`: это набор вопросов-ответов (основание, цифры, значение B).
- «Пример из условия» — `- пункт`: это последовательность шагов примера.
- «Два случая правила» — `связка: … | …` и строка `признак -> … | …`: два случая сравниваются рядом, как шеренга.

Как получен ответ: для N=1..15 шестнадцатеричная запись — одна цифра. Только у N=11 это B (нечётное количество), получается B1₁₆ = 177 — трёхзначное. У остальных 14 чисел B нет (0 — чётное), слева дописывается 1: 11₁₆..1F₁₆ = 17..31 — двузначные. При N≥16 запись уже не короче двух цифр, после дописывания 1 длина ≥3 шестнадцатеричных цифр, значение ≥ 100₁₆ = 256 — не двузначное. Итого 14.

Пополнение словаря отношений:
- перед — Х, У — цифра Х стоит перед цифрой У — факт.
- младше — Х, У — Х младше У (стоит раньше в порядке цифр) — перед; перед + младше.
