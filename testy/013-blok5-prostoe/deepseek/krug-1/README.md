# Школьная библиотека

Описание файлов и примера записи выдачи.

## Файлы

- `knigi.json` — данные: книги, читатели, выдачи.
- `knigi.html` — страница «Школьная библиотека» со списком книг.
- `knigi.css` — вид страницы.
