Причины выбора схем:
- Кусок 1 (шестнадцатеричная запись): батарея — один заголовок и несколько атрибутов под ним.
- Кусок 2 (пример по шагам): последовательность запоминателей — каждый шаг новое значение, идёт за предыдущим.
- Кусок 3 (два случая правила): шеренга — два случая рядом сравниваются по одному признаку.

Как получен ответ: R должно быть двухзначным (10–99). Для N от 1 до 15 hex — одна цифра, k = 0 кроме N = 11 (hex = 'B', k = 1). При чётном k (k = 0) единица дописывается слева, R = 16 + N, диапазон 17–31 — все двухзначные. N = 11 даёт k = 1 (нечётное), единица справа, R = int('B1', 16) = 177 — трёхзначное. Для N ≥ 16 hex состоит из двух и более цифр, R ≥ 256 — не двухзначное. Итого подходят N ∈ {1, 2, …, 10, 12, …, 15} — 14 чисел.

Пополнение словаря отношений:
- перед — цифра, цифра — первая стоит перед второй в порядке цифр — базовое отношение (факт)
- младше — цифра, цифра — первая младше второй в порядке цифр — из перед (простое), из перед и младше (рекурсивное)
