# ДРАКОН-лист: Дежурство

## Действия

```дракон
название: дежурный
ввод: den
ввод: grafik
вопрос: grafik имеет den?
  да: вывод grafik[den]
  нет: вывод ""
конец
```

## Данные

```конспект
тема: Дежурства и смены
режим: знания
A -> ?
B -> ?
дежурит Тимур -> понедельник
дежурит Глеб -> вторник
дежурит Вера -> среда
после понедельник -> вторник
после вторник -> среда
правило: A сменяет B, если дежурит A -> следующий_день и дежурит B -> текущий_день и после текущий_день -> следующий_день
пример: Глеб сменяет Тимура
контрпример: Тимур сменяет Глеба
запрос: кто сменяет Глеба
```

## Тест

- пример: ввод "вторник" и GRAFIK → вывод "Глеб"
- контрпример: ввод "вторник" и GRAFIK → вывод "Тимур"
