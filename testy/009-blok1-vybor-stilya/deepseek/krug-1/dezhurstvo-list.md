# ДРАКОН-лист: дежурство

## Действия

```дракон
название: dezhurnyj
ввод: den
ввод: grafik
imya = ''
для: zapis из grafik
  вопрос: zapis.den !== den
    да:
      к следующему шагу
    нет:
      imya = zapis.imya
вывод: imya
```

## Знания

```конспект
тема: Дежурство
режим: знания
А -> ?
Б -> ?
Д1 -> ?
Д2 -> ?
связь Тимур -> понедельник: дежурит
связь Глеб -> вторник: дежурит
связь Вера -> среда: дежурит
связь вторник -> понедельник: после
связь среда -> вторник: после
правило: А сменяет Б, если А дежурит Д2 и Б дежурит Д1 и Д2 после Д1
пример: Глеб сменяет Тимура
контрпример: Тимур сменяет Глеба
запрос: кто сменяет Глеба
```

## Тест

- пример: dezhurnyj('вторник', GRAFIK) → 'Глеб'
- контрпример: dezhurnyj('вторник', GRAFIK) → 'Тимур'
