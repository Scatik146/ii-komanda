# ДРАКОН-лист: проверка наличия цифры в пароле

## Действия

```дракон
название: Есть ли цифра в пароле
ввод: parol = input()
результат = False
для: символ в parol
  вопрос: символ — цифра?
    да: результат = True
    нет: (ничего не делаем)
вывод: результат
```

## Данные

```конспект
тема: Надёжный пароль
запоминатель: Надёжный пароль -> содержит всё сразу
  - хотя бы одна цифра
  - хотя бы одна заглавная буква
  - хотя бы один спецсимвол
```

## Тест

- пример: ввод "Pass123!" → вывод True
- контрпример: ввод "password" → вывод False
```
```

Пополнение словаря:
- «есть цифра в пароле» — средний слой — проверяет наличие цифры в строке-пароле — из операций ввода, цикла, вопроса и вывода;
- «надёжный пароль» — верхний слой — описывает требования к надёжному паролю — из трёх условий (цифра, заглавная буква, спецсимвол).
