````markdown
# ДРАКОН-лист: пароль

## Действия

```дракон
название: Есть ли цифра в пароле
ввод: parol = input()
result = False
для: simvol in parol
  вопрос: simvol.isdigit()
    да:
      result = True
    нет:
      result = result
вывод: result
```

## Данные

```конспект
тема: Надёжный пароль
Надёжный пароль -> это всё сразу
  - хотя бы одна цифра
  - хотя бы одна заглавная буква
  - хотя бы один спецсимвол
```

## Тест

- пример: ввод "abc1" → вывод True
- контрпример: ввод "abc1" → вывод False
````

Пополнение словаря: новых слов нет (только переменные parol, simvol, result).
