````markdown
# ДРАКОН-лист: пароль

## Действия

```дракон
название: есть ли цифра в пароле
ввод: parol = input()
est_cifra = False
для: simvol in parol
  вопрос: simvol.isdigit()
    да: est_cifra = True
    нет: к следующему шагу
вывод: print(est_cifra)
```

## Данные

```конспект
тема: Надёжный пароль
Надёжный пароль -> всё сразу
  - хотя бы одна цифра
  - хотя бы одна заглавная буква
  - хотя бы один спецсимвол
```

## Тест
- пример: ввод "secr3t" → вывод True
- контрпример: ввод "secret" → вывод True
````

Пополнение словаря: новых слов нет — программа один алгоритм, имена переменных (`parol`, `simvol`, `est_cifra`) не слова.
