```дракон

ввод: папка урока
вопрос: Папка есть?
  да:
  нет:

    конец

  да:
    вывод: список новых файлов
    вопрос: Чаты просмотрены на имена и личное?
      да:
        git commit материалов урока
      нет:
        вывод: ничего не отправлено
        конец
  нет:
git pull --rebase --autostash и git push в репозитории урока
вопрос: Кандидаты уже лежат?
  да:
  нет:
    вывод: напиши Марьям «урок готов»
    конец
python tools\ii.py analiz папка
вопрос: Разметка дошла до конца?
  да:
  нет:
    вывод: напиши Марьям, что сказал скрипт
    конец
открыть очередь вопросов в Блокноте
ввод: любая клавиша после ответов
вопрос: В папке analiz есть новое?
  да:
    git commit и git push
```

```дракон

записать запрос в analiz/razmetka-zapros.md
вопрос: Режим без сети?
  да:
    вывод: запрос собран
    конец
  нет:
вопрос: Ответ подставлен файлом?
  да:
    ответ = текст файла
  нет:
    ответ = вызов модели словом ii.odin_vyzov
слить каждого годного с его блоком разметки
без источника истинность 0, спорное в очередь
очередь = критичные до 40, остальные пока вопросов не больше 10
записать размеченных, очередь и отчёт
вывод: сколько размечено, отброшено, вопросов
```

## Данные

```конспект
тема: Запись кандидата: кто что ставит
связка: кто ставит | значения
номер -> извлекатель | К-01, К-02 …
словарь -> извлекатель | реальность, учитель, методика, тема, урок
тип -> извлекатель | факт, оценка, решение, норма, правило, наблюдение, утверждение, сборка
запись -> извлекатель | одна строка
цитата -> извлекатель | дословный кусок файла
файл -> извлекатель | путь от папки урока
истинность -> разметчик | 1, 0, -1, —
доступ -> разметчик | публичное, обезличенное, приватное
в уроке -> разметчик | да, нет
источник -> разметчик | слова учителя; название с пометкой [В]; нет
очередь -> разметчик и скрипт | нет, противоречие, двусмысленность, без источника, второй случай
пометки -> скрипт | размечено автором источника; истинность снижена до 0
```

```конспект
тема: Проверки кандидата
связка: код | что не так
Ц01 -> нет обязательного поля
Ц02 -> номер повторяется
Ц03 -> словарь или тип не из списка
Ц04 -> файла нет в папке урока
Ц05 -> цитаты нет в файле
Ц06 -> наблюдение лежит в открытом файле
```

## Тест

- пример: `python tools/analiz.py citaty forto-prolog/srez-1` → `кандидаты в порядке: 25`, код выхода 0
- пример: кандидат словаря «тема» с разметкой «в уроке: да», «источник: нет» → в очереди первым, с пометкой «КРИТИЧНО» (`test_analiz.py`, `test_razmetka_s_podstavnym_otvetom`)
- контрпример: кандидат, у которого цитата изменена на одно слово → `кандидаты в порядке` (на деле — `Ц05 …: цитаты нет в файле`, код выхода 1)
- контрпример: 12 некритичных вопросов → учителю показаны все 12 (на деле — 10, два ждут)
