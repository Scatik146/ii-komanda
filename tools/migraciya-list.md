# ДРАКОН-лист: migraciya.py — перенос папки команды в ii-komanda

16.11.2026, Марьям. Код — `migraciya.py`, правила — `migraciya-pravila.json`, запуск одной командой — `migraciya.bat` (рядом). Запуск из папки `ii-komanda`: `python tools\migraciya.py` (проба), `--sdelat`, `--proverit`; всё подряд — `tools\migraciya.bat`. Верхние слова: `napisat_probu`, `sdelat`, `proverit_posle`; разбор ключа — `glavnoe`.

## Данные

```конспект
тема: Правила переноса
связка: что делает | где строка «перенесено из»
perenos -> файл переезжает в ii-komanda | первой строкой (после #! или @echo off)
v_repo -> файл переезжает внутри своего репозитория | нет (номера строк не сдвигаются)
ukazatel -> на старом месте ссылка на новое | —
указатель в коде -> падает с адресом, код выхода 1 | —
```

```конспект
тема: Классы файлов
связка: что с путями | пример
zhivoj -> заменяются новыми | README.md, tools/
istoriya -> не трогаются | komnata/, testy/
navyk -> в таблицу для карточек, копия не меняется | rezerv/navyki/
```

```конспект
тема: Особые правила
связка: зачем | где лежат
osobye -> пути, которых общий разбор не видит | migraciya-pravila.json
ostavit -> верная строка про старую папку | migraciya-pravila.json
ne_chitat -> свои файлы миграции не разбирать | migraciya-pravila.json
ne_trogat -> чужой проект (max-class-bot) | migraciya-pravila.json
```

## Тест

- пример: `python tools/migraciya.py` на клонах 16.11 (ii-komanda 508ebd1 и соседи) → переносов 120, указателей 127, замен 89 в 24 файлах, путей в навыках 50, руками 0, битых 0, код выхода 0
- пример: `--sdelat` и `--proverit` на копии четырёх репозиториев (16.11) → 269 файлов, нет на месте 0, старых путей 0, битых 0; тест сайта `drakon-zapis-test` ✓
- контрпример: `--sdelat` при незакоммиченной правке → «Не делаю: не закоммичено», ничего не записано, код выхода 1
- контрпример: повторный `--sdelat` после переноса → «уже есть: …», код выхода 1
- контрпример: `--proverit` без `sdelano.json` → «сначала --sdelat», код выхода 1
- контрпример: старый путь в комментарии нового файла в `tools/` (шапка `migraciya.bat`, 16.11) → «руками 1», `--sdelat` откажет
