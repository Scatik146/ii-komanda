# `ii.py` — сборка урока командой ИИ (версия 0.1, 14.11.2026)

Устройство — `../ii-py/USTROJSTVO.md`, алгоритм — `../algoritm/v9.md`. Python 3, без установки пакетов.

## 1. Ключи на Windows (один раз)

1. Открыть Блокнот, вписать по строке на значение (образец — `.env.primer`; строки без ключа не писать):
   ```
   YANDEX_API_KEY=...
   YANDEX_FOLDER_ID=...
   DEEPSEEK_API_KEY=...
   ```
2. «Сохранить как» → папка `C:\Users\<имя>\`, имя файла `".ii-komanda.env"` (в кавычках, чтобы Блокнот не дописал `.txt`), кодировка UTF-8.
3. Файл лежит **вне** репозиториев — в GitHub и SourceCraft он не попадёт. Скрипт значения ключей не показывает.

## 2. Команды (из папки `ii-komanda`)

| Команда | Что |
|---|---|
| `python tools\ii.py klyuchi` | какие ключи найдены и какие модели отвечают; для Яндекса — список доступных моделей |
| `python tools\ii.py novyj <папка урока>` | новая папка урока с шаблонами `zayavka.md`, `resheniya.md` |
| `python tools\ii.py ekspertiza <папка урока>` | шаг 3: `ekspertiza.md` → `so-analiz.md`, затем СТОП 2 |
| `python tools\ii.py status <папка урока>` | какие файлы есть, вердикты стража |
| `python tools\ii.py proverka <папка урока> [код]` | проверка окружения (для приложения и презентации) + страж → `proverka/itog.md` |
| `python tools\ii.py zapros --rol kanva --prompt вход.md --vyhod выход.md` | один промпт в одну роль |

Общие ключи: `--bez-seti` — модели не вызываются, собранный промпт ложится в `proverka/<шаг>-zapros.md`; `--predel N` — не больше N вызовов (по умолчанию 40); `--modeli файл.json` — другой набор моделей.

Урок обычно лежит в teacher-workpad: `python tools\ii.py ekspertiza ..\teacher-workpad\chernoviki\<урок>`.

## 3. Модели

`modeli.json`: у каждой роли — порядок моделей (одна попытка повтора, потом следующая). Модель без ключа пропускается и пишется в `proverka/zhurnal.md`. Есть только ключ Яндекса — в `roli` поставить `"alisa"` (или открытую модель Яндекса из списка `klyuchi`) первой у нужных ролей; код не трогать.
