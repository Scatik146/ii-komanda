# `ii.py` — сборка урока командой ИИ (версия 0.2, 15.11.2026)

Устройство — `../ii-py/USTROJSTVO.md`, алгоритм — `../algoritm/v9.md`. Python 3, без установки пакетов.

## 1. Ключи на Windows (один раз)

1. Открыть Блокнот, вписать две строки (образец — `.env.primer`):
   ```
   YANDEX_API_KEY=...
   YANDEX_FOLDER_ID=...
   ```
2. «Сохранить как» → папка `C:\Users\<имя>\`, имя файла `".ii-komanda.env"` (в кавычках, чтобы Блокнот не дописал `.txt`), кодировка UTF-8.
3. Файл лежит **вне** репозиториев — в GitHub и SourceCraft он не попадёт. Скрипт значения ключей не показывает.

С 0.2 других ключей не нужно: все модели — через Яндекс (решение 14.11).

## 2. Урок по шагам v9 (из папки `ii-komanda`)

| Шаг | Команда | Что получится |
|---|---|---|
| — | `python tools\ii.py novyj <урок>` | папка с шаблонами `zayavka.md`, `resheniya.md` |
| 3 | `python tools\ii.py ekspertiza <урок>` | `proverka\ekspertiza-dlya-glm.md` — **скопировать целиком в чат GLM** |
| 3 | `python tools\ii.py ekspertiza <урок> --otvet ответ-glm.md` | ответ GLM → `ekspertiza.md`, Алиса делает `so-analiz.md` → **СТОП 2** |
| 4–6 | `python tools\ii.py sborka <урок>` | канва → шпаргалка, приложение, презентация, печатные → картинки (заказы), техкарта; каждый — окружение + страж, круги → `proverka\itog.md` → **СТОП 3** |
| приёмка | `python tools\ii.py vernut <урок> prilozhenie "что не так"` | старая версия → `proverka\starye\`, новая + проверка |
| выдача | `python tools\ii.py vydacha <урок>` | картинки из `assets\` вшиты, строгая проверка → `vydacha\` (нет картинки — «НЕТ КАРТИНКИ: имя, где стоит» в `proverka\vydacha.md`) |

После приёмки: `python tools\ii.py analiz <урок>` — кандидаты в словари из `<урок>\analiz\kandidaty.md` → разметчик (DeepSeek) → `analiz\ochered-uchitelyu.md`; одной командой с отправкой в GitHub — `tools\analiz.bat <урок>`. Правила — `komanda/srez-1/postanovka.md`.

Ещё: `klyuchi` — какие ключи найдены и какие модели отвечают; `status <урок>` — какие файлы есть, вердикты стража; `proverka <урок> [код]` — только проверка; `zapros --rol kanva --prompt вход.md --vyhod выход.md` — один промпт в одну роль.

`sborka` идёт подряд, сама; принятая канва (после `vernut kanva`) заново не собирается. Учитель нужен, когда:
- нет `so-analiz.md` (не пройден СТОП 2) — сборка не начинается;
- канва не принята за 2 круга или страж сказал `УЧИТЕЛЮ` — сборка останавливается, причина в `itog.md`;
- у артефакта исчерпаны 3 круга или `УЧИТЕЛЮ` — строка в `itog.md`, сборка идёт дальше;
- принят, но страж отметил «желательно» — строка в `itog.md` на приёмку (возврат — только за «критично», решение 15.11; если страж написал ВЕРНУТЬ без «критично», скрипт ставит ПРИНЯТЬ).

`--po-shagam` — ждать Enter перед каждым артефактом (`q` — остановить).

Общие ключи: `--bez-seti` — модели не вызываются, собранный промпт ложится в `proverka\<шаг>-zapros.md`; `--predel N` — не больше N вызовов (по умолчанию 40); `--modeli файл.json` — другой набор моделей.

Урок обычно лежит в teacher-workpad: `python tools\ii.py sborka ..\teacher-workpad\chernoviki\<урок>`.

## 3. Модели (`modeli.json`)

| Роль | Модель (Яндекс, один ключ) | Замена |
|---|---|---|
| `strazh`, `so_analiz` | Alice AI LLM | Alice AI LLM Flash |
| `rutina` | Alice AI LLM Flash | Alice AI LLM |
| `kanva`, `prilozhenie`, `kontent` | DeepSeek V4.1 Flash | Qwen 3.6 35B |
| `vizual` (промпты картинок) | Alice AI LLM Flash | DeepSeek |
| экспертиза | GLM — вручную через учителя | — |

Порядок: одна попытка повтора, потом следующая модель; всё пишется в `proverka\zhurnal.md`. Страж не проверяет сам себя.

**Рассуждение.** У DeepSeek и Qwen оно включено по умолчанию: у них `"rassuzhdenie": true` и `"max_tokens": 32000`; блок `<think>…</think>` из ответа убирается. Если в журнале «рассуждение съело лимит» — увеличить `max_tokens`; если «HTTP 400» с текстом про `max_tokens` — уменьшить. Как выключить рассуждение у Яндекса — не сверено; когда будет известно, параметр вписывается в `telo_dop` без правки кода. **Ожидание ответа** — `"tajmaut"` в описании модели, секунды (без него — 300); у DeepSeek 900: на серьёзных заданиях рассуждение идёт дольше 5 минут (012, 16.11).

## Тест кода: задание — модели, ответ — на проверку (`test_koda.py`, 15.11.2026)

Отдельный скрипт; ключи, список моделей и вызов Яндекса берёт из `ii.py`. Нужны: Python 3, Node.js, рядом с `ii-komanda` — папки `teacher-workpad` (навык, задания, проверки) и `drakon-graf`.

```
python tools\test_koda.py ..\teacher-workpad\docs\komanda\zadaniya\<задание>.md --model alisa
python tools\test_koda.py ..\teacher-workpad\docs\komanda\zadaniya\<задание>.md --model deepseek
```

- Модели: `alisa` — `aliceai-llm`, `deepseek` — `deepseek-v4.1-flash` (обе через ключ Яндекса). GLM — вручную, через комнату.
- Круг: ответ модели → файлы в `testy/<задание>/<модель>/krug-N/` → проверки из раздела задания «Проверки командой». Есть ошибки — второй круг с текстом ошибок. Кругов два.
- Строки «руками:» скрипт задаёт учителю один раз, по последнему кругу (`--bez-ruk` — не задавать).
- Итог — `testy/<задание>/<модель>/itog.md`: счёт первого и последнего круга, вывод непрошедших проверок. Раздел «Чтением» заполняет проверяющий.
- Без сети, для проверки самого скрипта: `--podstavit ответ1.md ответ2.md`.
- Внимание: проверки запускают код, написанный моделью, на этом компьютере.

### Одной командой: `test-zapusk.bat` (15.11.2026)

Из папки `ii-komanda`: `tools\test-zapusk.bat 011 alisa` (задание — номер или имя файла без `.md`; модель — `alisa`, `deepseek`, `glm`). Делает по порядку: для `glm` проверяет `otvet-glm.md` на следы копирования (`tools/chistyj_otvet.py`: `&#x20;`, `\[`) → `git pull --rebase` в ii-komanda и teacher-workpad → `test_koda.py` (для `glm` — `--podstavit otvet-glm.md`) → `git add testy`, `git commit -m "Тест навыка: <задание> · <модель>"`, `git push` (отклонён — `git pull --rebase` и снова). Ручные вопросы `test_koda.py` задаёт по ходу. ДРАКОН-лист — `test-zapusk-list.md`.

С 16.11: перед ручной проверкой `test_koda.py` открывает её файлы в Блокноте; если модель файл не сдала — вопрос не задаётся, в итоге «файл не сдан»; во втором круге модель получает образец оформления (имя — строкой вне ограды, `.md` — в ограде из четырёх кавычек); пути — с `\`.
