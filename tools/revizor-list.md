# ДРАКОН-лист: ревизор навыков и памяти

Код — `tools/revizor.py`, ядро — `yadro-trit/trit.py`, данные о видимости памяти — `komanda/revizor/vidimost.json`.
Программа ничего не удаляет и навыки не меняет: правки навыков — карточкой propose_skills, решение учителя.

## Действия

```дракон
название: Ревизия навыков и памяти
ввод: клон memory_maryam_ai, папка установленных навыков
если: есть vidimost.json, клон памяти и папка навыков
  да:
    А = самопроверка: пример и контрпример каждой проверки
    Б = пробы-мутанты: есть_ли, согласие, основание, или_всех, и, или испорчены в «да» — самопроверка говорит «нет»
    итог = меньшее из А и Б, встроенным min, а не словом ядра
    источники = навыки команды (установленные), память (общая и проекта), копии CLAUDE.md
    1. ссылки: есть_ли(нашёл, полный) — «нет» только при полном списке
    2. повторы: одинаково — да, похоже — не знаю; ненадёжный источник — основание(т, нет) = не знаю
    3. противоречия: один предмет, одно действие, согласие(+1, −1) = не знаю — кандидат учителю
    4. устаревшее: или_всех(срок прошёл, версия старше журнала, слово «пока / сейчас / possibly» вне цитат)
    5. копии навыков: совпадает — нет, расходится — да, навык не установлен — не знаю
    6. вес: на каждом запросе и по моменту, в байтах
    отчёт = komanda/revizor/otchet-<дата>.md
    вывод: сводка до полстраницы; код выхода: итог да 0, нет 1
  нет:
    вывод: «не знаю: нет входа»; код выхода 2
```

## Данные

```конспект
тема: Проверки ревизора и слова ядра
связка: собрано из
ссылка -> есть_ли
повтор -> основание
противоречие -> согласие
устаревшее -> или_всех, или
самопроверка -> min встроенный
стрелка: «нет» о ссылке — только если строка называет наш репозиторий не приставкой пути
стрелка: 0 — «не знаю», показывать учителю, а не прятать
```

## Тест

- пример: ii-komanda `yadro-trit/trit.py` → ссылка «да»
- пример: ii-komanda `komanda/net-takogo-fajla.md` → ссылка «нет»
- пример: teacher-workpad `lib/net-takogo.md` → ссылка «не знаю»
- пример: одна строка в открытом навыке и в другом файле → повтор «не знаю»
- пример: «SOSTOYANIE не писать» и «SOSTOYANIE обновить» → противоречие «не знаю» (кандидат)
- пример: «сдать до 01.01.2020» → устарело «да»; «possibly a GitHub Pages site» → «не знаю»
- контрпример: «обычная строка без срока» → не устарело; «Тело цикла «пока» справа» → не устарело (слово в цитате)
- контрпример: в копии ядра «и» = max → самопроверка «нет», код выхода 1 (проверено 25.11)
