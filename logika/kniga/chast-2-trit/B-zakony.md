# Часть 2. Трит. Шаг Б. Законы на тритах

В части 1 у нас было 33 закона. Мы их выучили, проверили и ими упрощали. Теперь в логике появилось «не знаю». Возникает простой вопрос: что из старого багажа можно взять с собой, а что придётся оставить на берегу.

## Б.1. Что держится

**Как проверять.**

Так же, как в части 1: подставить все наборы и сравнить левую и правую части. Только наборов стало больше. У одной буквы их теперь 3, у двух - 9, у трёх - 27.

Двадцать семь строк руками - это уже не проверка, это наказание. Поэтому считает программа. Ей не скучно. Ей вообще никогда не скучно - можно только позавидовать.

**Сначала - перевод.**

Законы части 1 написаны для битов. Чтобы проверить их на тритах, их надо аккуратно перевести. Договор у нас из А.0: бит 1 - это трит 1, бит 0 - это ложь, трит −1.

Значит, там, где в законе стоял 0, теперь пишем −1. Было x ∧ 0 = 0 - стало x ∧ −1 = −1. Было 0 → x = 1 - стало −1 → x = 1.

**Контрпример - «забыл перевести».** Оставим x ∧ 0 = 0, как было. Но 0 на тритах - это уже не «нет», а «не знаю». Подставим x = −1: −1 ∧ 0 = −1. А должно было получиться 0. Закон «сломался» - хотя сломали его мы сами.

«Не знаю» и «нет» - разные вещи. Это вообще главное, что надо унести из части 2. Можно прямо сейчас.

**Стрелки.**

Стрелку «если x, то y» по-научному зовут импликацией. В части 1 главный закон про неё был такой: x → y = ¬x ∨ y.

Его и возьмём за основу. Отдельную таблицу для стрелки на тритах заводить не будем - соберём стрелку из того, что уже есть, из НЕ и ИЛИ. А x ≡ y соберём из двух стрелок: (x → y) ∧ (y → x).

Получается, что эти два закона держатся по договору: мы сами их так записали. Остальные законы со стрелками программа проверяет честно, на всех наборах.

Тут честно предупрежу: со стрелкой на тритах не всё так просто. Её можно собрать и по-другому. Лукасевич из А.0, например, собрал свою, и кое-где она отвечает не так, как наша. Где именно и почему - разберём в шаге Г, когда дойдём до слова «следует».

Спорить с Лукасевичем пока рано. Договоримся так: в шаге Б стрелка - это ¬x ∨ y. И никак иначе.

**Ответ.**

Из 33 законов на тритах держатся 25. Все 8 законов со ★ - ломаются. Других сюрпризов нет: ни один закон без звёздочки не подвёл.

| Закон на тритах | Название | Группа части 1 |
|---|---|---|

| x ∧ −1 = −1 | с константой | 1 |
| x ∨ −1 = x | с константой | 1 |
| x ∨ 1 = 1 | с константой | 1 |
| x ∧ x = x | идемпотентность для И | 2 |

Группы 1, 3, 4 и 5 переехали целиком. Ни одной потери.

**Почему держатся.**

Секрет в min и max. Меньшее из трёх чисел не зависит от того, в каком порядке их сравнивать. Отсюда переместительные и сочетательные законы. Меньшее из одного и того же числа - это само число. Отсюда x ∧ x = x.

А НЕ на тритах - это смена знака. Если поменять знак у двух чисел, то меньшее станет большим, а большее - меньшим. Это и есть де Морган: НЕ заходит в скобку и меняет И на ИЛИ.

**Пример - де Морган с «не знаю».** Вчера было собрание. Учитель там был: 1. Был ли сосед - не знаю: 0. «Неправда, что были оба»:

¬(1 ∧ 0) = ¬0 = **0**.

По де Моргану: «учитель не был ИЛИ сосед не был»:

¬1 ∨ ¬0 = −1 ∨ 0 = **0**.

Совпало. И честно: раз про соседа ничего не известно, то и про «неправда, что оба» ничего не известно.

**Пример - поглощение.** «Соседка была на собрании» ИЛИ «соседка была там вместе с учителем». Про соседку не знаем: 0. Учитель был точно: 1.

0 ∨ (0 ∧ 1) = 0 ∨ 0 = **0**.

Ровно столько же, сколько и про одну соседку. Вторая половина фразы уже сидела внутри первой - как и на битах.

**Пример - распределительный.** x = 0, y = −1, z = 1.

Слева: 0 ∧ (−1 ∨ 1) = 0 ∧ 1 = **0**.
Справа: (0 ∧ −1) ∨ (0 ∧ 1) = −1 ∨ 0 = **0**.

Совпало. Программа проверила все 27 наборов - совпадает везде.

**Пример - контрапозиция.** «Если пошёл дождь, то сосед взял зонт». Дождь пошёл: 1. Взял ли сосед зонт - не знаем: 0.

1 → 0 = ¬1 ∨ 0 = −1 ∨ 0 = **0**.

Перевернём: «если сосед без зонта, то дождя нет».

¬0 → ¬1 = 0 → −1 = ¬0 ∨ −1 = 0 ∨ −1 = **0**.

Одно и то же «не знаю» - с какой стороны ни заходи.

**Контрпример - «раз законы держатся, переедет всё».** Не переедет. Восемь законов со ★ остались на берегу. Самый знаменитый из них сломается сразу, как только туда заглянуть: x ∨ ¬x при x = 0 даёт 0 ∨ 0 = 0, а не 1. Подробно про ★ - в Б.2.

**Контрпример - «проверю на битах, этого хватит».** На битах, то есть на −1 и 1, держатся все 33 закона, звёздочки тоже. Но биты - это углы таблицы, 4 строки из 9. Все поломки ★ сидят в середине, там, где есть 0. Значит, проверять нужно всё.

Проверено программой: `logika/kniga/proverka_B2.py` (все 33 закона на всех наборах, ★ сверены с частью 1, примеры и контрпримеры, таблица этого раздела).

Двадцать пять из тридцати трёх. Для переезда - очень даже неплохо *)

## Б.2. Что ломается

Восемь законов со ★ не переехали. Посмотрим, где именно каждый споткнулся. И почему.

**Где ломается.**

Программа перебрала все наборы и выписала те, где левая часть не совпала с правой.

| Закон | Название | Где ломается | Слева | Должно быть |
|---|---|---|---|---|
| x ∨ ¬x = 1 | исключённого третьего | x = 0 | 0 | 1 |
| x ∧ ¬x = −1 | противоречия | x = 0 | 0 | −1 |
| (x ∧ y) ∨ (x ∧ ¬y) = x | склеивание для ИЛИ | x = 1, y = 0 | 0 | 1 |
| (x ∨ y) ∧ (x ∨ ¬y) = x | склеивание для И | x = −1, y = 0 | 0 | −1 |
| x ∨ (¬x ∧ y) = x ∨ y | Блейка - Порецкого для ИЛИ | x = 0, y = 1 | 0 | 1 |
| x ∧ (¬x ∨ y) = x ∧ y | Блейка - Порецкого для И | x = 0, y = −1 | 0 | −1 |
| x → x = 1 | из себя | x = 0 | 0 | 1 |
| (x ∧ (x → y)) → y = 1 | модус поненс | x = 0, y = −1; x = 0, y = 0; x = 1, y = 0 | 0 | 1 |

У восьми законов вместе 54 набора. Ломаются из них 10. Семь законов ломаются ровно в одной строке, модус поненс - в трёх.

**Первое, что видно: везде есть 0.**

Ни одной поломки без «не знаю». На −1 и 1 все восемь держатся - это мы видели в Б.1. Значит, ломает их именно третье значение.

**Второе: ломается всегда одинаково.**

Посмотрите на два последних столбца. Слева - всегда 0. Должно быть - всегда 1 или −1.

Закон обещает знание. А честный счёт на тритах выдаёт «не знаю».

И ни разу не наоборот. Ни разу не вышло −1 там, где обещали 1. Закон на тритах не врёт. Он молчит.

**Почему.**

Посмотрим, что у восьми законов общего. В каждом буква стоит рядом со своим отрицанием: x и ¬x или y и ¬y.

В x → x этого сразу не видно. Но стрелка у нас - это ¬x ∨ x. То есть x → x - тот же закон исключённого третьего, только в другой одежде.

В модусе поненс пар даже две. Если расписать стрелки через НЕ и ИЛИ, получится ¬x ∨ (x ∧ ¬y) ∨ y: здесь и x с ¬x, и y с ¬y. Поэтому и строк поломки у него три, а не одна.

На битах из пары x и ¬x одно обязательно равно 1. Третьего не дано. Это и есть две строки из А.2: ответ уже решён и известен. Законы со ★ написаны только для них - даже если в формуле этого не видно.

На тритах при x = 0 и x, и ¬x - «не знаю». Опереться не на что.

**Пример - исключённого третьего.** «Сосед был на собрании ИЛИ сосед не был». Был ли - не знаем: 0.

0 ∨ ¬0 = 0 ∨ 0 = **0**.

Закон обещал 1. Но откуда бы ей взяться? В обеих половинах - «не знаю». Если бы из двух «не знаю» сложилось «да», мы бы что-то узнали, ничего не проверив.

Из незнания знание не получается. Ни через И, ни через ИЛИ.

Тут обычно спрашивают: «Но ведь сосед правда либо был, либо не был!» Правда. Только это знание о мире. А трит считает другое - что знаем мы. А мы про соседа не знаем ничего.

А если спросить про завтра - «сосед придёт ИЛИ не придёт», - то не знает и сам мир. Это строка (0, 1) из А.2: ответа пока нет ни у кого.

**Пример - противоречия.** «Сосед был на собрании И сосед не был».

0 ∧ ¬0 = 0 ∧ 0 = **0**.

Закон обещал −1: так не бывает. Мы-то это понимаем. Но счёт видит только два «не знаю» и честно отвечает «не знаю».

**Пример - склеивание.** «Учитель был на собрании, и сосед был» ИЛИ «учитель был, а сосед не был». Учитель был точно: 1. Про соседа не знаем: 0.

(1 ∧ 0) ∨ (1 ∧ ¬0) = 0 ∨ 0 = **0**.

А по закону должно выйти x, то есть 1. На битах сосед тут ни при чём: в одной половине он точно есть, в другой точно нет, и учитель «склеивается». На тритах сосед застрял в обеих половинах. И утащил учителя за собой.

**Пример - Блейк - Порецкий.** «Соседка была на собрании» ИЛИ «соседка не была, а учитель был». Про соседку не знаем: 0. Учитель был точно: 1.

Слева: 0 ∨ (¬0 ∧ 1) = 0 ∨ 0 = **0**.
Справа - «соседка была ИЛИ учитель был»: 0 ∨ 1 = **1**.

Учитель в левой части есть. Но он спрятан за «соседка не была», а это тоже «не знаю». На битах это «не» ничего не портило. На тритах оно заперло учителя.

Выходит, на битах две формулы равны, а на тритах одна знает больше другой. Важно не только что сказано, но и как.

**Пример - модус поненс.** Напомню: модус поненс - по-латински «утверждающий способ». Это самое обычное рассуждение со словом «значит»: если x, то y; x есть; значит, y.

«Если идёт дождь, то сосед берёт зонт. Дождь идёт. Значит, сосед с зонтом». На битах такое рассуждение верно всегда - на нём держится любое «значит». Дождь идёт: 1. Про зонт не знаем: 0.

Правило: 1 → 0 = ¬1 ∨ 0 = **0**. Само «если дождь - то зонт» теперь под вопросом.
Обе посылки вместе: 1 ∧ 0 = **0**.
Всё рассуждение: 0 → 0 = ¬0 ∨ 0 = **0**.

Закон обещал 1: «рассуждение верно». Вышло «не знаю». И понятно почему: правило, в котором не уверены, ничего не гарантирует.

**Контрпример - «значит, законы со ★ неверные».** Нет. На битах все восемь держатся, программа это проверила. Они верны там, где третьего не дано. А третье мы добавили сами.

**Контрпример - «починим: пусть x ∨ ¬x всегда даёт 1».** При x = 0 это 0 ∨ ¬0, то есть 0 ∨ 0. А 0 ∨ 0 - это max, и он равен 0, так договорились в А.1. Значит, чтобы починить закон, придётся сломать ИЛИ. Невыгодный обмен.

Проверено программой: `logika/kniga/proverka_B2.py` (все наборы, где ломается каждый ★; в каждой поломке есть 0; слева всегда «не знаю», справа - знание; примеры раздела; таблица раздела сверена с программой).

Что от восьми законов всё-таки остаётся - в Б.3.

Законы не сломались. Они просто отказались врать *)
