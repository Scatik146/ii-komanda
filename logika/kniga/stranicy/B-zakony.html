Часть 1. Бит. Шаг Б. Законы

Черновик раздела книги и страницы сайта. Каждый пример проверен программой proverka_primerov.py.

Б.1. Законы по группам

Закон - равенство, которое верно всегда. При любых x, y, z. Не «обычно», не «почти всегда» - всегда.

Как убедиться? Таблицей истинности. У двух букв - 4 строки, у трёх - 8. Посчитал обе части - совпали во всех строках - закон. Не совпали хоть в одной - не закон. Одной строки хватит, чтобы закон рухнул.

Зачем законы, если есть таблица? Таблица отвечает «верно или нет». А закон показывает, как упростить. Таблица - проверка. Закон - инструмент.

Значок ★ - закон, на котором споткнётся осторожный человек из части 2. На битах он верен. На тритах - нет. Почему - узнаем позже. Пока просто запомним, где лежат грабли.

Группа 1. С константами

Закон Пример
x ∧ 1 = x (a ∨ b) ∧ 1 = a ∨ b
x ∧ 0 = 0 (a → b) ∧ 0 = 0
x ∨ 0 = x ¬a ∨ 0 = ¬a
x ∨ 1 = 1 (a ∧ b) ∨ 1 = 1

Как в арифметике: умножить на 1 - ничего не изменится, умножить на 0 - получится 0. Только ИЛИ с единицей сюрприз: x ∨ 1 = 1. В арифметике x + 1 так себя не ведёт. Логика - не совсем арифметика. Об этом - Б.3.

Контрпример - «с нулём тоже сюрприз». x ∨ 0 = 1? Нет. Подставим x = 0: 0 ∨ 0 = 0. Сюрприз только с единицей.

Группа 2. Сам с собой

Закон Название Пример
x ∧ x = x идемпотентность для И (a ∨ b) ∧ (a ∨ b) = a ∨ b
x ∨ x = x идемпотентность для ИЛИ ¬a ∨ ¬a = ¬a
¬¬x = x двойное отрицание ¬¬(a ∧ b) = a ∧ b
x ∨ ¬x = 1 ★ исключённого третьего (a ∧ b) ∨ ¬(a ∧ b) = 1
x ∧ ¬x = 0 ★ противоречия a ∧ b ∧ ¬a = 0

«Идемпотентность» - страшное слово для простой вещи. Сказал «да» два раза - это всё равно одно «да».

Двойное отрицание: «неправда, что я не пришёл» - значит, пришёл.

Контрпример. «x ∧ ¬x = 0 - значит, x ∨ ¬x тоже 0». Нет. Подставим x = 1: 1 ∨ 0 = 1. Законы для И и для ИЛИ - пары, но не близнецы.

Группа 3. Порядок не важен

Закон Название Пример
x ∧ y = y ∧ x переместительный для И (коммутативность) ¬a ∧ a = a ∧ ¬a
x ∨ y = y ∨ x переместительный для ИЛИ (коммутативность) ¬a ∨ b ∨ a = a ∨ ¬a ∨ b = 1
(x ∧ y) ∧ z = x ∧ (y ∧ z) сочетательный для И (ассоциативность) (a ∧ b) ∧ c = a ∧ (b ∧ c)
(x ∨ y) ∨ z = x ∨ (y ∨ z) сочетательный для ИЛИ (ассоциативность) (a ∨ b) ∨ c = a ∨ (b ∨ c)

Это скучные законы. Но без них ничего не работает. Именно они разрешают писать a ∧ b ∧ c без скобок и переставлять буквы, чтобы нужные оказались рядом.

Контрпример. Для стрелки порядок важен. a → b и b → a - разные функции. При a = 1, b = 0: 1 → 0 = 0, а 0 → 1 = 1. Переставлять можно только у И, ИЛИ (и у ≡, ⊕ - но это потом).

Группа 4. Раскрываем скобки

Закон Название Пример
x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z) распределительный И относительно ИЛИ (дистрибутивность) a ∧ (b ∨ ¬a) = (a ∧ b) ∨ (a ∧ ¬a) = a ∧ b
x ∨ (y ∧ z) = (x ∨ y) ∧ (x ∨ z) распределительный ИЛИ относительно И (дистрибутивность) a ∨ (b ∧ ¬a) = (a ∨ b) ∧ (a ∨ ¬a) = a ∨ b

Первый закон - как в алгебре: 2 · (3 + 4) = 2 · 3 + 2 · 4.

Второй - в алгебре неверен: 2 + 3 · 4 = 14, а (2 + 3) · (2 + 4) = 30. А в логике - верен. Вот тут логика и арифметика расходятся по-настоящему.

Группа 5. НЕ над скобкой

Закон Название Пример
¬(x ∧ y) = ¬x ∨ ¬y де Моргана для И ¬(a ∧ ¬b) = ¬a ∨ b
¬(x ∨ y) = ¬x ∧ ¬y де Моргана для ИЛИ ¬(¬a ∨ ¬b) = a ∧ b

Правило одной строкой: НЕ заходит в скобку - и переворачивает знак. И становится ИЛИ, ИЛИ становится И.

«Неправда, что я сделал и алгебру, и физику» - значит, не сделал алгебру или не сделал физику. Может, обе. Но хотя бы одну - точно.

Контрпример - самая частая ошибка. ¬(a ∧ b) = ¬a ∧ ¬b? Подставим a = 1, b = 0. Слева: ¬(1 ∧ 0) = ¬0 = 1. Справа: 0 ∧ 1 = 0. Не совпало. НЕ зашло в скобку, а знак не перевернули.

Кто такой. Огастес де Морган. Родился в 1806 году в Индии, в Мадуре, - отец служил там офицером. Вырос в Англии, стал профессором математики в Лондоне.

1847 год. Де Морган выпускает книгу «Формальная логика». И тут же получает обвинение в плагиате. Обвиняет сэр Уильям Гамильтон из Эдинбурга, сам логик. Подаренную книгу Гамильтон вернул неразрезанной. Не читал, но осуждаю.

Спор вышел громкий. Его заметил Джордж Буль - и в том же году выпустил свой «Математический анализ логики». С этого и началась алгебра логики (А.0).

Самому де Моргану хватило благородства. Работу Буля он хвалил и помогал ему.

А правило про НЕ над скобкой знали и до него. Имя досталось ему - за то, что записал чётко и формулами.

Подробнее - в «Действующих лицах»: де Морган, Гамильтон, Буль.

Группа 6. Сокращаем

Закон Название Пример
x ∧ (x ∨ y) = x поглощение для И (a ∧ b) ∧ (a ∧ b ∨ c) = a ∧ b
x ∨ (x ∧ y) = x поглощение для ИЛИ ¬a ∨ (¬a ∧ c) = ¬a
(x ∧ y) ∨ (x ∧ ¬y) = x ★ склеивание для ИЛИ (¬a ∧ b ∧ c) ∨ (¬a ∧ ¬b ∧ c) = ¬a ∧ c
(x ∨ y) ∧ (x ∨ ¬y) = x ★ склеивание для И (a ∨ b) ∧ (a ∨ ¬b) = a
x ∨ (¬x ∧ y) = x ∨ y ★ Блейка - Порецкого для ИЛИ ¬c ∨ (c ∧ d) = ¬c ∨ d
x ∧ (¬x ∨ y) = x ∧ y ★ Блейка - Порецкого для И a ∧ (¬a ∨ b) = a ∧ b

Самые полезные законы. Ими формулы и худеют.

Поглощение: «я приду» ИЛИ «я приду с другом» - это просто «я приду». Второе уже внутри первого.

Склеивание - то, что мы делали в А.4. Две скобки отличаются одной буквой: где-то b, где-то ¬b. Значит, b не важно. Выбрасываем.

Блейк - Порецкий: «x ИЛИ (не x, но y)». Если x верно - всё верно. Если не верно - смотрим на y. Слово «не x» тут лишнее: до него дело доходит, только когда x уже ложно.

Кто такие. Платон Порецкий - астроном Казанского университета. Взялся за логику, когда коллега дал ему редкую книгу Буля. В 1887-1888 учебном году прочитал первый в России курс математической логики.

Арчи Блейк - Чикагский университет, диссертация 1937 года. Склеивай и поглощай, пока можно, - получишь самую полную ДНФ.

Вместе они не работали. Порецкий умер в 1907-м, Блейк защитился через 30 лет. Два имени в одном законе - это наши учебники так их поженили.

Подробнее - в «Действующих лицах»: Порецкий, Блейк.

Контрпример - «склеиваю всё, что похоже». (a ∧ b) ∨ (¬a ∧ ¬b). Отличаются две буквы, а не одна. Склеить в «ничего» нельзя. Это вообще не константа - это эквивалентность a ≡ b. При a = 1, b = 0 она равна 0.

Группа 7. Стрелки

Закон Название Пример
x → y = ¬x ∨ y импликация через ИЛИ a ∧ b → c = ¬a ∨ ¬b ∨ c
x → y = ¬y → ¬x контрапозиция (a → ¬b) = (b → ¬a)
¬(x → y) = x ∧ ¬y отрицание импликации ¬(a → b ∨ c) = a ∧ ¬b ∧ ¬c
1 → x = x из единицы 1 → a ∧ b = a ∧ b
0 → x = 1 из нуля 0 → a = 1
x → x = 1 ★ из себя a ∨ b → a ∨ b = 1
(x ∧ y) → z = x → (y → z) экспортация a ∧ b → c = a → (b → c)
(x ∧ (x → y)) → y = 1 ★ модус поненс (a ∧ (a → b)) → b = 1
x ≡ y = (x → y) ∧ (y → x) эквивалентность через стрелки a ≡ b = (a → b) ∧ (b → a)
x ≡ y = (x ∧ y) ∨ (¬x ∧ ¬y) эквивалентность через И, ИЛИ, НЕ a ≡ ¬b = (a ∧ ¬b) ∨ (¬a ∧ b)

Главный закон группы - первый. Стрелка «если x, то y» - это «не x ИЛИ y». Запомнить его - и любую стрелку можно разобрать на И, ИЛИ, НЕ.

Контрапозиция: «если идёт дождь, то асфальт мокрый» - то же самое, что «если асфальт сухой, то дождя нет».

Из нуля - что угодно: 0 → x = 1. «Если я китайский император, то я умею летать» - формально верно. Император из меня никакой, так что обещание не нарушено. Звучит дико. Но так устроена стрелка.

Контрпример - «перевернул стрелку». x → y = y → x? Нет. «Если дождь, то мокро» не значит «если мокро, то дождь». Может, дворник с шлангом прошёл. Перевернуть можно только с двумя НЕ - это контрапозиция.

Контрпример - экспортация не про скобки у стрелок. (a → b) → c и a → (b → c) - разное. При a = 0, b = 0, c = 0: (0 → 0) → 0 = 1 → 0 = 0, а 0 → (0 → 0) = 1. Вот почему в А.1 две стрелки подряд - всегда скобки.

Контрпример - «поглощение везде одно». Откроешь вузовские лекции Алексеева - там тоже есть «законы поглощения». Но другие: x ∨ x = x, x ∨ ¬x = 1, x ∧ ¬x = 0 и законы с константами. Наше x ∨ (x ∧ y) = x там под этим словом не стоит. Одно слово - два смысла. Смотри на формулу, а не на название.

Откуда названия. Первое - школьное. В скобках - как у Алексеева, если он этот закон называет. Склеивания, Блейка - Порецкого, контрапозиции и законов про стрелку у Алексеева нет: так их называют школьные учебники.

Источники формулировок: справочник logika/dvoichnaya.md (все 33 закона проверены программой dvoich.py на всех наборах). Научные названия: Алексеев В. Б. Лекции по дискретной математике. - М.: МГУ, 2004, §1, с. 8–9. Школьные - сверить с учебником Полякова - Ерёмина (Р82).

Б.2. Упрощаем по шагам

Законы - инструменты. Теперь работаем.

Правило одно: один шаг - один закон. Записываем, что было, какой закон применили и что стало. Не «ну тут очевидно». Очевидное - это где чаще всего и ошибаются.

Пример 1. Почему работает склейка

В А.4 мы склеивали скобки и обещали объяснить. Объясняем.

Шаг: было = стало Закон
(a ∧ b) ∨ (a ∧ ¬b) = a ∧ (b ∨ ¬b) распределительный (читаем справа налево - выносим a за скобку)
a ∧ (b ∨ ¬b) = a ∧ 1 исключённого третьего ★
a ∧ 1 = a с константой

Три шага - и склейка доказана. Заодно видно, почему она ★: держится на «b или не b - всегда 1». У осторожного человека это не так.

Пример 2. Отрицание стрелки

Шаг: было = стало Закон
¬(a → b) ∨ (a ∧ b) = (a ∧ ¬b) ∨ (a ∧ b) отрицание импликации
(a ∧ ¬b) ∨ (a ∧ b) = a склеивание для ИЛИ ★

Итого: ¬(a → b) ∨ (a ∧ b) = a. Длинная формула оказалась одной буквой.

Пример 3. Де Морган, потом склейка

Шаг: было = стало Закон
(a ∨ b) ∧ ¬(¬a ∧ b) = (a ∨ b) ∧ (¬¬a ∨ ¬b) де Моргана для И
(a ∨ b) ∧ (¬¬a ∨ ¬b) = (a ∨ b) ∧ (a ∨ ¬b) двойное отрицание
(a ∨ b) ∧ (a ∨ ¬b) = a склеивание для И ★

Пример 4. Стрелки разбираем на детали

Шаг: было = стало Закон
(a → b) ∧ (¬a → b) = (¬a ∨ b) ∧ (¬¬a ∨ b) импликация через ИЛИ (два раза)
(¬a ∨ b) ∧ (¬¬a ∨ b) = (¬a ∨ b) ∧ (a ∨ b) двойное отрицание
(¬a ∨ b) ∧ (a ∨ b) = (b ∨ ¬a) ∧ (b ∨ a) переместительный для ИЛИ
(b ∨ ¬a) ∧ (b ∨ a) = b склеивание для И ★

По-человечески: «если a, то b» и «если не a, то b». Как ни крути - b. «Если будет дождь - пойду в кино. Если не будет - тоже пойду в кино». Значит, просто пойду в кино.

Тут был шаг «переместительный». Скучный закон. Но без него склеивание не узнать: оно хочет одинаковую букву впереди.

Как проверить себя

Последний шаг сравнить с первым таблицей. Две-три буквы - это 4 или 8 строк, минута работы. Совпало - упрощение верное. Не совпало - ищем шаг, где закон применили не тот.

Контрпример - «вынес за скобку, которой нет». Хочется: a ∧ b ∨ c = a ∧ (b ∨ c). Как в алгебре, «вынес a». Но c не умножено на a! Проверка: a = 0, b = 0, c = 1. Слева: 0 ∨ 1 = 1. Справа: 0 ∧ 1 = 0. Не совпало. Выносить можно только то, что есть в каждой скобке.

Контрпример - «сократил, как дробь». (a ∨ b) ∧ (a ∨ c) = b ∧ c - «a же есть и там, и там». Нет. Проверка: a = 1, b = 0, c = 0. Слева: 1 ∧ 1 = 1. Справа: 0. Верно вот так: (a ∨ b) ∧ (a ∨ c) = a ∨ (b ∧ c) - это распределительный закон, группа 4.

Б.3. Логика - это арифметика

Бит - это 0 или 1. А 0 и 1 - это числа. Значит, можно не выдумывать новые знаки, а считать по-школьному: плюс, минус, умножить.

Логика Арифметика на 0 и 1 Ещё проще
¬x 1 − x
x ∧ y x · y min(x, y)
x ∨ y x + y − x · y max(x, y)
x ⊕ y (x + y) по модулю 2
x → y 1 − x + x · y
x ≡ y 1 − x − y + 2 · x · y

Проверено программой proverka_arifmetiki.py на всех наборах.

НЕ - это «сколько не хватает до единицы». И - умножение: хоть один ноль - всё ноль. ИЛИ - почти сложение. Почти.

А теперь законы. Многие из них - просто школьная алгебра:

x · x = x - идемпотентность. Какое число, умноженное само на себя, даёт само себя? Решаем x² = x: x² − x = 0, x · (x − 1) = 0. Корни - 0 и 1. Только они. Других нет.

Вот почему у бита два значения. Не потому, что кто-то так решил. Это единственные два числа, для которых x · x = x.

x · (1 − x) = 0 - закон противоречия ★. «x И не x». Один из множителей обязательно ноль: либо x, либо 1 − x.

x + (1 − x) = 1 - исключённого третьего ★. «x ИЛИ не x». Тут даже формула ИЛИ не нужна - произведение x · (1 − x) всё равно 0, вычитать нечего.

Де Морган - тоже алгебра. Слева ¬(x ∧ y) = 1 − x · y. Справа ¬x ∨ ¬y = (1 − x) + (1 − y) − (1 − x)(1 − y). Раскроем скобки: 2 − x − y − 1 + x + y − x · y = 1 − x · y. Совпало. Без единой таблицы.

Контрпример - «ИЛИ это просто плюс». 1 + 1 = 2. А бит не бывает двойкой. Поэтому в ИЛИ есть поправка «− x · y»: она срабатывает ровно тогда, когда обе единицы, и убирает лишнюю. Python, кстати, про это не знает: True + True там равно 2. Кто писал на ЕГЭ сумму условий вместо or - тот в курсе *)

Контрпример - «тогда x + x = x». Для ИЛИ верно: x ∨ x = x. Для плюса - нет: 1 + 1 = 2. Идемпотентность есть у умножения и у ИЛИ, но не у сложения.

Мостик в часть 2. Посмотрите на столбец «Ещё проще». И = min, ИЛИ = max. Эти две записи не знают, что значений всего два. Им всё равно - бит, трит, хоть оценка в журнале. А вот x · x = x знает: корни только 0 и 1.

Добавим третье значение - и формулы с умножением сломаются, а min и max останутся. Вместе с умножением зашатаются законы, которые держатся на «x или не x = 1» и «x и не x = 0». Это ровно те, что со значком ★.

Но это уже другая история.
