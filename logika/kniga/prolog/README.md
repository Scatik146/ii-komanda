# Пролог-слова части 2 «Трит»

Те же примеры и контрпримеры, что в Python-проверках `logika/kniga/proverka_*.py`, - вторая, независимая проверка формул.

**Принцип - фортовский:** от простого к сложному, сборкой. Нижний уровень - основной базис тритов {и, не, ворота, 0}. Каждое следующее слово собрано только из уже собранных. Где получается, мелочь сведена к крупным словам.

| файл | что |
|---|---|
| `bazis.pl` | базис; ИЛИ, не знаю?, возможно; основание, согласие, есть ли, срабатывает; векторы; механика проверки |
| `chast2-A.pl` | А.0 пара тритов, А.1 НЕ/И/ИЛИ, А.2 девять вариантов, ворота наружу |
| `chast2-B.pl` | 33 закона части 1 на тритах: 25 держатся, 8 ★ ломаются, что остаётся |
| `chast2-V.pl` | согласие, основание, ворота, сборка окошками всех 27 и 19 683 действий, четыре замка |
| `chast2-G.pl` | стрелка Клини, Лукасевич, Брусенцов буквально, пустой класс |
| `chast2-D.pl` | перебор вариантов; неотвратимо = основание(согласие всех, полный); может быть = есть ли(ИЛИ всех, полный); Вальд в целых числах |
| `chast2-E.pl` | Е.0 табличка; Е.1 закон Мерфи = «может быть», готовиться = возможно(может быть); Е.2 девять правил |
