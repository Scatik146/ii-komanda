## 1. Решение о полной системе (**1 — решено автором 19.11, 16:41**)

**Вопрос.** Описываем ли мы недостающие функции, чтобы система работала целиком и к ней возвращались только ради правки?
**Решение автора:** да, и **временные операторы** обязательно — «прямо чувствую, что облегчит нам жизнь». Набор временных операторов — на сверке (§ 2.4). Ход работы — вопрос за вопросом, по порядку.

Система — это **три слоя**. Каждая функция живёт ровно в одном слое.

| Слой | Вопрос, на который отвечает | Что на выходе | Куда можно писать |
|---|---|---|---|
| **Значения** | правда ли? проверено ли? | 1 / 0 / −1 | `ист`, `пров` |
| **Вывод** | следует ли одно из другого? для всех ли? есть ли? | 1 / 0 / −1 | `ист` выведенного атома |
| **Действия** | выдать? менять? искать? придумывать? | делать (1) / не делать (−1) | только журнал решений, **не** `ист`/`пров` (ОЧ-17) |

**Пример целиком.** «Все слова урока проверены?»
- *Вывод:* ищем контрпример — слово с `пров ≠ 1`. Нашли — ответ −1. Список закрыт, а контрпримера нет — 1. Одно слово в работе и не определено — 0.
- *Действие:* ворота `L` выдают урок только при 1.
- *Контрпример:* если бы «не нашли» считалось «нет» без закрытого списка, урок со словом, которое забыли внести, ушёл бы наружу. Это запрещают ОЧ-13 и Б3.

Почему не импликация. Импликация K3 `max(¬x, y)` при ложной посылке даёт 1: «из ничего следует всё». Наше следование при `Vx = −1` (x-вещей нет) даёт −1.
*Пример:* «все драконы умеют летать» при пустом списке драконов в K3 — истина, у нас — нет следования.
Брусенцов: «импликация не есть следование». Таблица Ф12 по форме совпадает с Ф6 («запрет»), но с другим смыслом аргументов: найденный контрпример запрещает следование.

**Условие закрытого списка (часть Ф13 и Ф15).** Пролог по умолчанию считает «нет в базе» ложью. У нас это −1 только для списков, которые автор объявил полными. Иначе — 0 или «нет» (ОЧ-13, Б3).

**Два трита и будущее (мысль автора 19.11, 16:58; разбор Марьям, 0 — на сверке).**
1. *Пара (`ист`, `пров`).* Про будущее до срока проверить нечем → основания нет → `пров = 0` (ОЧ-01). Тогда ворота ОЧ-05 `L(ист ∧ пров)` сами не выпускают прогноз наружу, даже если в нём `ист = 1`. 2. *Пара Брусенцова (Vx, Vx′) по вариантам.* Vx — есть вариант, где x; Vx′ — есть вариант, где не x. (1, 0) — во всех x: неотвратимо будет (Т8 = 1). (0, 1) — неотвратимо не будет (−1). (1, 1) — **σ, привходящее, «то быть, то не быть»**: будущее действительно случайно (Т8 = 0, Т9 = 1) → держать под рукой. (0, 0) — вариантов нет: «нет», не знаем ничего → строить варианты, искать (Ф11). Пара различает **два разных нуля**: «варианты расходятся» и «вариантов нет». Наше наблюдение: σ Брусенцова (о совокупностях) и ½ Лукасевича (о будущем) восходят к одному месту Аристотеля и совпадают, если совокупность — это варианты будущего (0, проверить).

**Почему это наше.** Третье значение Лукасевич ввёл (1920) именно для высказываний о случайном будущем — «морское сражение» Аристотеля. Прайор начал логику времени со статьи «Three-Valued Logic and Future Contingents» (1953), где защищал систему Лукасевича. Наш 0 про будущее — прямой наследник. Прогноз осторожного человека = пирсовское «будет» (Т8): «да» только то, что наступает во **всех** вариантах.

Не уверен — не обещай.** *Афоризм автора (19.11, 17:17); формула **принята автором 19.11, 18:04**.* Обещать можно только неотвратимое: `обещать(φ) = L(неотвратимо φ)` (Т8 по закрытому списку вариантов) — или своё собственное действие, по которому ты принял решение. Остальное — долей (Т10) или прогнозом с подписью. *Пример:* «урок в пятницу будет» (расписание, твоё решение) — можно; «Петя получит пять» — нельзя, говори «писал на пять 9 из 10».
