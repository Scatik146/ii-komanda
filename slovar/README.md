# Словарь — вселенная проекта ii-komanda

Вселенная — это словарь проекта, эта папка. Не атом, поля `опирается` у неё нет (решение автора 17.11.2026). Стыковка с другими проектами — через приставку проекта во внешних ссылках: `ii-komanda/0001`.

- `slovar/` — основной словарь, постоянные номера `0001…`; номер не меняется и не выдаётся повторно.
- `slovar/kandidaty/` — кандидаты, временные номера `9000–9999`; при подъёме получают постоянный номер, ссылки переписывает программа.
- Доступ определяет папка: здесь — публичное. Приватные атомы — в `memory_maryam_ai/slovar/`.

Миры: `0001` Реальность (опирается на себя), `0002` мир книги, `0003` учебный урок; у каждого мира оговорка (`0004`–`0006`). Список миров строит программа; этот перечень — для чтения человеком.

Псевдопамять: `python3 ii-py/slovar/pamyat.py slovar 0001 0002 0003 9004 9001 9005 > slovar/PAMYAT.md` — адреса по первому появлению при сборке.
