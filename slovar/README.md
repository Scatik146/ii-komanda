# Словарь — вселенная проекта ii-komanda

Вселенная — словарь проекта, эта папка. Не мир и не атом (решения автора 17.11.2026). Стыковка с другими проектами — через приставку проекта во внешних ссылках: `ii-komanda/0001`.

```
slovar/
  sistema/                 служебное вселенной: PAMYAT.md, позже реестр и счётчик номеров
  0001-realnost/           мир Реальность: карточка мира, оговорка, атомы мира
    kandidaty/             кандидаты этого мира (номера 9000–9999)
    0002-mir-knigi/        мир, опирающийся на Реальность
    0003-uchebnyj-urok/
```

- **Мир — подпапка с номером** (`NNNN-imya/`); внутри — карточка мира, его оговорка и атомы, впервые появившиеся в этом мире. Служебные папки — без номера.
- **Опора мира вычисляется из пути:** мир внутри мира опирается на внешний. Папка Реальности лежит прямо во вселенной, поэтому Реальность опирается сама на себя — единственная петля. Поля `опирается` в карточках нет.
- **Номера:** постоянные `0001…` — не меняются и не выдаются повторно; кандидаты — `9000–9999`, при подъёме получают постоянный номер, ссылки переписывает программа. Счётчик — один на вселенную.
- **Доступ определяет место:** здесь — публичное; приватные атомы — `memory_maryam_ai/slovar/`.

Псевдопамять (адреса по первому появлению при сборке):

```
python3 ii-py/slovar/pamyat.py slovar 0001 0002 0003 9004 9070 9005 > slovar/sistema/PAMYAT.md
```
