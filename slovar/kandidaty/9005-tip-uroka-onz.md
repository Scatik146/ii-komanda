Тип урока «открытие нового знания» по Петерсон: девять этапов, порядок не меняется. Форма работы «практикум» ставится на этапах, а не здесь.

```prolog
% этап_типа(Тип, Номер, Этап).
этап_типа(9005, 1, 'мотивация (самоопределение) к учебной деятельности').
этап_типа(9005, 2, 'актуализация и фиксирование индивидуального затруднения в пробном действии').
этап_типа(9005, 3, 'выявление места и причины затруднения').
этап_типа(9005, 4, 'построение проекта выхода из затруднения').
этап_типа(9005, 5, 'реализация построенного проекта').
этап_типа(9005, 6, 'первичное закрепление с проговариванием во внешней речи').
этап_типа(9005, 7, 'самостоятельная работа с самопроверкой по эталону').
этап_типа(9005, 8, 'включение в систему знаний и повторение').
этап_типа(9005, 9, 'рефлексия учебной деятельности на уроке').
```

пример: `этап_типа(9005, 9, Э)` даёт рефлексию.
контрпример: `этап_типа(9005, 10, _)` — десятого этапа нет.
