Корень системы. Любая форма собирается из граф, а свойства самой графы — тоже графы: петля замыкается здесь и только здесь (как `опирается: 0001` у Реальности).

```prolog
% графа(Номер, Имя, Домен, Сколько, Обязательно, Заполнение).
%   Домен       — имя домена из атомов 9010–9014;
%   Сколько     — одно | список;
%   Обязательно — 1 (да) | -1 (нет) | 0 (по условию; условие — отдельное правило, пока не заведено);
%   Заполнение  — руками | 'из списка' | программа.

% свойства графы описаны графами (самоописание корня):
графа(9003, имя,         текст,  одно, 1, руками).
графа(9003, домен,       текст,  одно, 1, руками).
графа(9003, сколько,     список([одно, список]), одно, 1, 'из списка').
графа(9003, обязательно, троичное, одно, 1, 'из списка').
графа(9003, заполнение,  список([руками, 'из списка', программа]), одно, 1, 'из списка').
```

пример: `графа(9042, время, целое, одно, 1, руками)` — графа «время» описана верно.
контрпример: `графа(9042, время, целое, одно, 2, руками)` — «2» не троичное значение.
