- **Вывод:** `graf.pl` ищет своим `prove/2` с ограничением глубины 50 — это временная заплатка пробы. Она может обрезать вывод и дать ложное «контрпример не выводится». В обычном SWI-Prolog без таблирования такое правило зацикливается. Смысл режима знаний — таблирование (`FORTO-PROLOG-BLOKI.md` § 3). Чтобы в браузере и на сервере работал один код, `graf.pl` нужно перевести с `kb_clause` + `prove/2` на настоящие правила с `:- table` — отдельное задание.
- `zapis.js` (DrakonZapis 1.2): текст после `делать:` молча выбрасывается; `|` в `ввод:` — ошибка, хотя описание записи говорит «есть». Расхождения — `020-otvet-glm.md`.

## 5. Решения Р28, Р29 — что из них следует

- В словаре на уровне вселенной: `vhod/`, `biblioteka/`, `vyhod/` (рядом с `0001-realnost/`).
- Формат атома (020, часть А) — заодно формат обмена между вселенными: наш выход — чужой вход.
- Исходник после разбора — атом библиотеки (выходные данные, лицензия, доступ, `файл:`). Факты ссылаются на него с местом (`источник: [Н] 0123, с. 45`) — О16 сможет проверить существование источника.
- Разбор — по надобности: из словаря на 250 000 слов берутся только использованные слова.
- Цель разбора бывает исследовательской: «что можно взять, какие миры создать, от каких наследовать». Ответ — предложение; мир создаёт человек, оговорка мира — вместе с ним (Р15).
- Интернет-источник: адрес, дата обращения, снимок в веб-архиве (Robust Links: адрес оригинала, адрес снимка, дата). У критичных фактов — ещё своя копия (приватно) и хэш; при смене хэша у зависящих фактов сбрасывается «проверено» (Р9). Постоянный идентификатор (DOI, ISBN) — в шапку.
- Что взято из международных требований: ISO 690:2021 (однозначные машинно-разбираемые ссылки; данные, программы, веб-архивы); Chicago 18 (дата обращения — записывать в работе, печатать по требованию); FAIR (метаданные живут, даже когда данных уже нет; лицензия и происхождение); BibTeX / CSL-JSON для вывода списка источников. Действуют ли ГОСТ Р 7.0.5-2008 и ГОСТ Р 7.0.100-2018 без замены — проверить.

## 7. Логика (18.11, после 15:33)

- Р30 — «Логика очень осторожного человека»: пара 3+2, K3 + двоичное «и» для «проверено» (`sled-shagi.md`).
- Найдено: K3 в записи −1, 0, 1 — «и» = min, «или» = max, «не» = −x, эквивалентность = произведение; импликация K3 (`max(−a, b)`) — не «≤»; «≤» — импликация Ł3. Двухбитовая запись (за, против): 1 = (1,0), −1 = (0,1), 0 = (0,0); связки K3 — двоичные по битам; (1,1) — противоречие (О17).
- Человеческое рассуждение в исследованиях лучше описывает Ł3 (семантика слабого пополнения, Хёлльдоблер и др.); для «плотных» программ она совпадает с обоснованной семантикой (WFS) — тем, что даёт таблирование SWI-Prolog. K3 — правило осторожной базы знаний, не описание человека.
- ТВМ / ДССП-Т (НИЛ троичной информатики ВМК МГУ): NEG, TMIN, TMAX, TMUL совпадают со связками K3 (TMUL — эквивалентность); BRS — троичное ветвление, не связка (поправка 18.11 по выжимке `brusentsov.md` § 5.3); систему логики статьи не называют. Брусенцов — «трёхзначная логика Аристотеля», критика материальной импликации у Лукасевича. Выжимка — задание GLM и Claude Free → `brusentsov.md`.
