# Правила очень осторожного человека (формально)

«Логика очень осторожного человека» — название и принцип учителя (Р30, Р54). Каждое правило записано в форме **ЕСЛИ … ТО …** с запретом и источником. Часть **А** решена автором. Часть **Б** содержит кандидатов из законов Мерфи (идея учителя, 19.11; пересказ — Марьям). У кандидатов значение 0: правилами они становятся только после «да» автора.

## Обозначения

- `a`, `b` — атомы; `w` — мир; `Р` — Реальность (`0001`).
- `ист(a, w)` ∈ {1, 0, −1, нет} — истинность атома в мире; «нет» значит, что атом отсутствует (не значение).
- `пров(a)` ∈ {1, 0, −1} — проверено.
- `эксп(a)` ∈ {1, 0, −1} — сколько проверки нужно.
- `стат(a)` ∈ {черновик = −1, автопроверка = 0, ручная проверка = 1} — сколько проверки пройдено.
- `зав(b, a)` — `b` зависит от `a`: `a` входит в `состав` атома `b` или служит посылкой при выводе `b`.
- `наружу(a, w)` — атом выдаётся ученикам или в выгрузку (`как-лист`, `vyhod/`) из мира `w`.
- `реш(x)` — автор принял решение по `x`.
- `min`, `max` — «и», «или» по K3.

## А. Действующие правила

| № | Правило | Запрещено | Источник |
|---|---|---|---|
| ОЧ-01 | **Неизвестное.** ЕСЛИ для значения `x` нет основания (проверки или `реш`), ТО `x = 0` | переход 0 → 1 или 0 → −1 без основания: по умолчанию, по отсутствию возражений, «по вероятности» | Р54 |
| ОЧ-02 | **Два трита.** Значение атома = (`ист(a, w)`, `пров(a)`); вычисляются и сообщаются вместе. ЕСЛИ значение 0 по смыслу невозможно, ТО трит берёт только {1, −1} | сообщать одно без другого | Р55 |
| ОЧ-03 | **Проверено.** `пров(a)` = −1, ЕСЛИ `стат(a)` = черновик; ИНАЧЕ 0, ЕСЛИ `эксп(a)` = 0; ИНАЧЕ 1, ЕСЛИ `стат(a) ≥ эксп(a)`; ИНАЧЕ −1 | записывать `пров` руками или хранить (ОЧ-10) | Р54, Р75, Р77, Р79 |
| ОЧ-04 | **Правило нуля.** ЕСЛИ `зав(b, a)` и (`ист(a, w)` = 0 или `пров(a)` = 0), ТО `наружу(b, w)` запрещено, пока нет `реш`. Для составного: `ист(b) = min` по частям, `пров(b) = min` по частям | пропуск наружу при 0 в любой части | Р67 |
| ОЧ-05 | **Ворота наружу.** `наружу(a, w)` ⇔ `ист(a, w)` = 1 и `пров(a)` = 1. ИНАЧЕ выгрузка отказывает с ошибкой | выдача при истинности 1 без проверено 1 | Р76 |
| ОЧ-06 | **Черновик.** ЕСЛИ `стат(a)` = черновик, ТО ручная проверка и экспертиза не назначаются | тратить экспертизу на черновик | Р77 |
| ОЧ-07 | **Ответ из мира вопроса.** Ответ на вопрос в мире `w` = `ист(a, w)`; `w` по умолчанию = `Р`. ЕСЛИ значения в других мирах не запрошены, ТО в ответ не входят | выкладывать все миры и признаки без запроса | Р80 |
| ОЧ-08 | **Миры не складываются.** `ист(a, w)` = своя запись, ИНАЧЕ запись опоры по цепи опор (Р2), ИНАЧЕ «нет» | вычислять `ист(a, w)` из миров, не лежащих на цепи опор `w` (в том числе `max` по мирам) | Р2, Р80 |
| ОЧ-09 | **Частота.** Значение `v` хранится, ЕСЛИ частота обращений к `v` делает пересчёт дороже, чем хранение и сброс; ИНАЧЕ вычисляется. ЕСЛИ частота неизвестна (0), ТО вычисляется | хранить «на всякий случай» | Р78 |
| ОЧ-10 | **Одно место.** ЕСЛИ `v` вычислимо из хранимых полей, ТО `v` не хранится. ЕСЛИ хранится по ОЧ-09, ТО сбрасывается при любой смене источника | второе хранилище одного знания без сброса | Р79, Р34 |
| ОЧ-11 | **Не удалять — переносить.** Неиспользуемое переносится: файл входа → архив (Р57); атом → `slovar/arhiv/` → история git, на месте остаётся ссылка (Р68, Р74). Перенос не меняет `стат` и `версия` (Р70) | удаление без следа; засорение библиотеки | Р57, Р68, Р70, Р74 |
| ОЧ-12 | **Нет числа — нет механизма.** ЕСЛИ параметр механизма не задан автором, ТО механизм выключен | подставлять значение по умолчанию | Р72 |
| ОЧ-13 | **Отсутствие.** ЕСЛИ записи нет ни в `w`, ни в его опорах, ТО `ист(a, w)` = «нет»; «нет» ≠ 0 и «нет» ≠ −1; правило с посылкой «нет» не срабатывает | считать отсутствие ложью или гипотезой | Р3 |
| ОЧ-14 | **Честная условность.** Мир, расходящийся с опорой, допустим, ЕСЛИ у него есть оговорка мира. Утверждение такого мира, поданное как факт опоры, — ошибка | условность без оговорки | 16.11, Р15 |
| ОЧ-15 | **Спор вселенных.** ЕСЛИ две вселенные дают про `a` разные значения, ТО `ист(a, Р)` = 0; значения хранятся в мирах-признаках, дочерних к `Р`, по одному на признак (`a` в признаке выдаётся по ОЧ-07 с подписью признака) | выбирать победителя без признака | Р65, Р66, Р80 |
| ОЧ-16 | **Бланк.** ЕСЛИ у элемента формы `обязательно` = 0, ТО бланк с прочерком в нём не принят | принимать прочерк, пока автор не решил | Р59, Р67 |

## Б. Кандидаты из законов Мерфи (0 — ждут автора)

| № | Закон Мерфи (пересказ) | Правило | Запрещено |
|---|---|---|---|
| ОЧ-Б1 | Если можно сделать неправильно, кто-нибудь так и сделает | ЕСЛИ нарушение правила ОЧ-xx ведёт к `наружу`, ТО у правила должна быть проверка в программе, которая отказывает. ЕСЛИ проверки нет, ТО правило считается 0 (не действует) | полагаться на внимательность исполнителя |
| ОЧ-Б2 | Ничто не так просто, как кажется | ЕСЛИ утверждение («просто», «очевидно», «всегда так») не имеет примера и контрпримера, ТО его `ист` = 0 | принимать очевидное без примера |
| ОЧ-Б3 | Если кажется, что всё хорошо, значит, что-то упустил | Результат «ошибок не найдено» даёт `пров` не выше уровня пройденной проверки; полнота проверки = 0, пока её не подтвердил второй проверяющий | считать «не нашли» за «нет» |
| ОЧ-Б4 | Каждое решение порождает новые проблемы | ЕСЛИ принято решение `Рn`, ТО до внесения в документы оно сверяется с решениями `Р1…Рn−1`, затрагивающими те же поля и правила | вносить решение без сверки |
| ОЧ-Б5 | Последнюю ошибку находят после сдачи | ЕСЛИ `эксп(a)` = 1, ТО до `наружу(a)` проверяет не автор `a`, без контекста команды (новый чат) | выдача, проверенная только автором |
| ОЧ-Б6 | С одними часами знаешь время, с двумя — не уверен | ЕСЛИ одно знание лежит в двух местах и они не сверены, ТО его значение = 0 | брать любое из двух |
| ОЧ-Б7 | Любое объяснение поймут неправильно | ЕСЛИ проверяющий получил пересказ или сжатый текст, ТО результат проверки = 0. Проверка чтения обязательна | проверять по пересказу |
| ОЧ-Б8 | Всё ломается в самый неподходящий момент | Каждое действие над словарём имеет обратное (перенос, метка git, ссылка). ЕСЛИ действие необратимо, ТО нужен `реш` | необратимое действие без решения автора |

## Для автора: те же правила афоризмами

**Действующие**
- ОЧ-01. Не знаю — значит 0. Ноль сам не становится ни «да», ни «нет».
- ОЧ-02. У всего два вопроса: правда ли и проверено ли.
- ОЧ-03. Автор не решил — значит, проверено быть не может. Черновик всегда «не дошло».
- ОЧ-04. Один ноль держит всю цепочку.
- ОЧ-05. Наружу — только «и там, и там 1».
- ОЧ-06. Черновики на экспертизу не носят: это расход времени и сил.
- ОЧ-07. Не говори лишнего, если тебя не спрашивают.
- ОЧ-08. Из «не знаю здесь» и «да там» не получается «да».
- ОЧ-09. Частота обращения определяет необходимость действия.
- ОЧ-10. Одно знание — одно место.
- ОЧ-11. Не выбрасывай — перекладывай и оставляй записку, куда.
- ОЧ-12. Не знаешь числа — не включай механизм.
- ОЧ-13. Чего нет — того нет: это не ложь и не догадка.
- ОЧ-14. Сказка — не ошибка, если честно сказано, что это сказка.
- ОЧ-15. Двое спорят — я пишу «не знаю» и запоминаю, кто и почему.
- ОЧ-16. Не решил, обязательна ли графа, — прочерк не принимаю.

**Кандидаты из законов Мерфи**
- ОЧ-Б1. Мерфи: «если можно сделать неправильно, так и сделают». Осторожный: опасную дверь запирают замком, а не табличкой.
- ОЧ-Б2. Мерфи: «ничто не так просто, как кажется». Осторожный: «очевидно» — это 0, покажи пример.
- ОЧ-Б3. Мерфи: «всё хорошо — значит, что-то упустил». Осторожный: «не нашли» не значит «нет».
- ОЧ-Б4. Мерфи: «решения порождают проблемы». Осторожный: принял решение — перечитай соседние.
- ОЧ-Б5. Мерфи: «последнюю ошибку найдут после сдачи». Осторожный: чужие глаза — до сдачи.
- ОЧ-Б6. Мерфи: «с двумя часами не знаешь времени». Осторожный: двум часам не верю, пока не сверил.
- ОЧ-Б7. Мерфи: «любое объяснение поймут неправильно». Осторожный: пересказ — это 0, читаю подлинник.
- ОЧ-Б8. Мерфи: «ломается в самый неподходящий момент». Осторожный: делаю только то, что можно отменить.
- Мерфи: «бутерброд падает маслом вниз». Осторожный: мажу над газетой.
