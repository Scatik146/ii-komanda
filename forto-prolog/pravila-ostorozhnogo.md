# Правила очень осторожного человека (формально)

«Логика очень осторожного человека» — название и принцип учителя (Р30, Р54). Каждое правило записано в форме **ЕСЛИ … ТО …** с запретом и источником. Часть **А** решена автором. Часть **Б** содержит кандидатов из законов Мерфи (идея учителя, 19.11; пересказ — Марьям). У кандидатов значение 0: правилами они становятся только после «да» автора.

## Обозначения

- `a`, `b` — атомы; `w` — мир; `Р` — Реальность (`0001`).
- `ист(a, w)` ∈ {1, 0, −1, нет} — истинность атома в мире; «нет» значит, что атом отсутствует (не значение).
- `пров(a)` ∈ {1, 0, −1} — проверено.
- `эксп(a)` ∈ {1, 0, −1} — сколько проверки нужно.
- `стат(a)` ∈ {черновик = −1, автопроверка = 0, ручная проверка = 1} — сколько проверки пройдено.
- `зав(b, a)` — `b` зависит от `a`: `a` входит в `состав` атома `b` или служит посылкой при выводе `b`.
- `наружу(a, w)` — атом выдаётся ученикам или в выгрузку (`как-лист`, `vyhod/`) из мира `w`.
- `реш(x)` — автор принял решение по `x`.
- `min`, `max` — «и», «или» по K3.

**Пояснение к ОЧ-05 (учитель 20.11, не новое правило).** Ворота пропускают прямо или через НЕ ровно две пары из девяти: (1, 1) и (−1, 1). Это и есть биты двоичной логики: ответ уже решён и известен. Значит, двоичная логика — мир за воротами ОЧ-05; она годится для решённого (прошлое, настоящее, решённое будущее). Нерешённое будущее — пара (0, 1): «точно знаю, что ответа пока нет»; «не знаю» — (0, 0). Оба — 0 по ОЧ-01, различает их ОЧ-02. Троичная логика работает со всеми временами. Книга: часть 2, А.2 «Две строки из девяти»; проверка — `logika/kniga/proverka_A2.py` (`dve_stroki`).

### Находка: ворота не монотонны

Ф4 и Ф5 переводят 0 в −1 или в 1, а ОЧ-01 это запрещает. Противоречия здесь нет: выход ворот — **не истинность, а действие** («выдать / не выдать»). У ворот −1 значит «не выдаётся», а не «ложь». Кандидат в правила: **ОЧ-17 — выход ворот (Ф4, Ф5) нельзя записывать в `ист` и `пров`**, он живёт только как решение о действии.
