# Пара (признак записи, ответ) - материал для части про Форто-Пролог

Решения учителя 20.11 (README § 4, 20:04–20:15). Код, не книга о тритах.

Оба поля - триты, только −1, 0, 1 (константа ОТСУТСТВУЕТ = 2 убирается).
Признак: 1 - запись есть, −1 - записи нет (смотрели - пусто), 0 - не знаю, есть ли запись (не смотрели).

| признак | ответ | смысл | правило |
|---|---|---|---|
| 1 | 1 | записано «да» | запускается |
| 1 | 0 | записано «не знаю» - это ответ | запускается (возможно) |
| 1 | −1 | записано «нет» - ответ, из него можно делать вывод | не запускается |
| −1 | 0 | смотрели - пусто: вопроса не было | не запускается, вывода нет |
| 0 | 0 | не смотрели | не запускается, можно сходить проверить |
| −1 | ±1 | ответ без записи - выдумка | запрещено |
| 0 | ±1 | ответ при неизвестной записи - слухи, догадка | запрещено |

Три нуля в ответе различаются только парой: (1, 0) «не знаю» записано; (−1, 0) вопроса не было; (0, 0) не проверили.

Правило данных: признак не 1 → ответ 0. Запрещённое сочетание - ошибка данных: стоп, не вычисление.

**Срабатывает = ворота(признак) ∧ возможно(ответ)** - собрано из действий книги (В.3), не новое действие. Проверено на всех 9 парах: `proverka_pary.py` - всё верно. На запрещённых парах формула тоже даёт −1 (ворота не пропускают) - ошибка данных правило не запустит.
