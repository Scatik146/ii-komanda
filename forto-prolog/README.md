# «Форто-Пролог» — всё в одном месте

Модель знаний команды: атомы (элементарные и составные), шкала 3+3. Здесь — всё, кроме самой модели и заданий.

> **Главный принцип проекта (учитель, 18.11, Р54):** при любом решении исходить из **нашей троичной логики** (K3: 1 / 0 / −1, «неизвестно» — честное третье значение, не «нет») и принципа **«Логика очень осторожного человека»**: неизвестное не превращается ни в «да», ни в «нет»; к ученикам и наружу проходит только 1. Значение атома — всегда **два трита** (Р55): где нейтральное не нужно, трит берёт только 1 и −1 («3+2» — частный случай «3+3»). Закрепить в «Основаниях» постановки и в модели; учитывать на ревизии. Слова учителя: «всегда исходи из нашего варианта троичной логики при принятии решения и принципа "Очень осторожный человек"».
