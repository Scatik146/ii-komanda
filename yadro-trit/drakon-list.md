# ДРАКОН-лист: ядро троичной логики и его проверка

Код — `trit.py` (слова) и `proverka.py` (проверка). Эталон — `logika/kniga/prolog/bazis.pl`.

## Действия

```дракон
название: Проверка ядра
ввод: путь к drakon-graf
А = меньшее из ответов строк «пример» и «контрпример» эталона
если: есть swipl или путь к drakon-graf
  да:
    Б = да, если таблицы 16 слов совпали с Прологом, иначе нет
  нет:
    Б = не знаю
итог = меньшее из А и Б, встроенным min, а не словом «и» ядра
вывод: итог; код выхода: да 0, нет 1, не знаю 2
```

## Данные

```конспект
тема: Слова ядра снизу вверх
связка: из каких слов
базис -> не, и, ворота, 0
не_и -> и, не
или -> не_и, не
погасло -> ворота, не
не_знаю -> погасли_оба, погасло, не
возможно -> погасло, не
подтвердить -> или, с_нулём
основание -> подтвердить, и, не
согласие -> подтвердить, и, или
есть_ли -> подтвердить, не
сл -> или, не
неотвратимо -> основание, согласие_всех
может_быть -> есть_ли, или_всех
стрелка: 0 — «не знаю» (учитель 25.11)
```

## Тест

- пример: ядро как есть, путь к drakon-graf дан → «Итог ядра: да», код 0
- пример: путь не дан, swipl нет → «не знаю», код 2
- контрпример: в копии ядра «и» = max → итог «да» (так было до правки 25.11; теперь «нет», код 1)
