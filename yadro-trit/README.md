## Пополнение словаря

`имя — слой — что делает — из каких слов собрано`

- `не`, `и`, `ворота`, `ноль` — нижний — базис — встроенные `-x`, `min`, сравнение
- `трит`, `это_трит` — нижний — имя значения; трит ли — словарь `ИМЕНА`, `ТРИТЫ`
- `не_и`, `или`, `погасло`, `погасли_оба`, `с_нулём` — средний — ¬(x∧y), большее, ¬ворота, a∧¬ворота(x), x∧0 — базис
- `не_знаю`, `возможно`, `подтвердить` — средний — только 0; всё, кроме −1; «нет» только с подтверждением — погасло, или
- `основание`, `согласие`, `есть_ли`, `срабатывает` — верхний — действия книги (В) — подтвердить, и, или, не
- `сл`, `экв` — верхний — следование по Клини (`chast2-B.pl`) — или, не, и
- `согласие_всех`, `или_всех`, `и_всех`, `неотвратимо`, `может_быть` — верхний — списки вариантов (`chast2-D.pl`) — согласие, или, и, основание, есть_ли
- `вектор1`, `вектор2` — служебный — таблицы 3 и 9 клеток — слово по `ТРИТЫ`
