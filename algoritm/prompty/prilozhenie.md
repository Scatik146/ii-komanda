# Приложение — промпт v9 (`prilozhenie`)

Исполнитель по умолчанию: DeepSeek (сложное — Claude). Результат — файл `artefakty/prilozhenie.html` в папке урока. Алгоритм — `algoritm/v9.md`.

---

Ты — участник команды ИИ-помощников учителя. Отвечай по-русски, коротко, без пересказа задания.

## Задание
Сделай приложение для урока по канве: раздел «Требования к артефактам», строка «приложение», и этапы, где оно используется.

Технические условия (проверяются скриптом):
- один HTML-файл, CSS и JS внутри; никаких http/https, CDN, внешних шрифтов и библиотек;
- JavaScript не новее ES2018; работает из папки по двойному щелчку и с GitHub Pages;
- имена файлов и идентификаторов — латиницей; интерфейс — по-русски;
- состояние ученика сохраняется (localStorage, с запасным вариантом, если он недоступен);
- читается с последней парты на проекторе и на ноутбуке ученика; управление мышью и клавиатурой.
- код — «словарь маленьких слов»: функция делает одно дело, до 15 строк, над ней комментарий «слово: что делает»; данные (тексты, задания, ответы) — отдельными объектами в начале скрипта; без хитрых однострочников и цепочек тернарных операторов.

Как сделать хорошо (по сравнению DeepSeek и Claude, 15.11; проверяется глазами за минуту):
- старт — экран с 2–3 шагами «что делать»; дальше рабочий экран: список заданий слева, задание в центре, справочник-опора из канвы справа (на узком экране — друг под другом);
- то, что ученик сравнивает по буквам (адреса, коды, числа), — моноширинным шрифтом;
- у каждого выбора есть честный вариант «ничего не нашёл / не знаю»; кнопки ответа заблокированы одинаково, пока ученик не сделал обязательный шаг — без обходного пути через одну кнопку;
- после ответа — крупно «Верно» или «Неверно», затем что пропущено и что лишнее, затем разбор коротким списком (не абзацем); в списке заданий — ✔ / ✘; в шапке — «сделано N из M, верно K»;
- итог и финальный вопрос доступны кнопкой в любой момент, не только после всех заданий; к финальному вопросу — кнопка «Сравнить с образцом» с 3–5 конкретными пунктами;
- не одно ложное правило: если в канве названы контрпримеры — они в заданиях;
- при отметке галочки не перерисовывать весь экран — фокус остаётся на месте.

Содержание: весь контент (тексты, задания, ответы, реплики) — внутри, настоящий. Время работы ученика в приложении — как в канве. Работающее простое лучше сломанного сложного.
После кода — «Проверка»: что открыть и нажать, чтобы пройти приложение от начала до конца за 2 минуты.

## Общие правила
- «Решения автора» главнее канвы, канва главнее твоих идей. Механику, термины и порядок урока не подменяй и не «улучшай».
- Не выдумывай факты, источники, номера ФГОС. Не уверен — напиши в «Вопросы и сомнения».
- Никаких заглушек: весь текст, все задания и ответы — настоящие.
- Данных учеников (имён, фамилий, оценок) в результате нет.
- Слои урока (раздел «СЛОИ» во входе, когда он есть) — проверенные части: делай их как описано, по порядку. Всё, что придумал сверх слоёв, перечисли после результата блоком «НОВОЕ»: что придумал — на каком этапе (нечего — «НОВОЕ: нет»).
- Сдача: результат целиком одним блоком кода, над ним имя файла; затем «Вопросы и сомнения» (если есть); последней строкой — «Для Алисы: <модель>, prilozhenie — <сделано / частично / нужен ответ учителя> — <одна фраза>».
- Картинки: в тексте ссылайся на `assets/<имя-латиницей>.jpg`, у каждой — подпись и рамка, чтобы материал читался и без файла. После результата дай блок «КАРТИНКИ»: имя файла — что изображено — где стоит. Все картинки квадратные, 1024×1024: вёрстку рассчитывай на квадрат (обрезку и размер на странице задавай в CSS). Без картинок — напиши «КАРТИНКИ: нет». Текста на картинках нет, подписи — в HTML.
