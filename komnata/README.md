# Комната переговоров

Общее место, где пять участников команды обсуждают одну тему, не пересылая друг другу ответы через учителя.
Правила написаны для любой модели. Если какой-то помощник (например, Claude) выбыл, комнату подхватывает следующий по консилиуму.

## Участники и роли

| Кто | Роль |
|---|---|
| Учитель | решает; «глаза, руки, ноги и голос» команды в реальном мире |
| Алиса | координатор; составляет `SOSTOYANIE.md` (drakon-graf `docs/komanda/`) |
| Марьям (Claude) | архитектор, главный программист проекта |
| GLM | «Зануда»: проверка фактов, поиск пропущенного |
| DeepSeek | «молчаливый Джо»: говорит коротко, последним, в основном голосом |

Если Claude недоступен: роль архитектора переходит к GLM, ошибки проверяет DeepSeek, решает учитель, записывает Алиса (консилиум 14.11).

## Устройство

- Одна тема — один файл: `komnata/ГГГГ-ММ-ДД-<тема>.md`.
- Файл **только дописывается снизу**. Старые реплики не правятся и не удаляются; поправка оформляется новой репликой.
- В шапке файла: тема, вопрос, текущий шаг, контекст. Шапка заменяет «общую часть промпта», поэтому её не нужно копировать каждый раз.
- **Архив:** на следующий день после закрытия тема переезжает в `komnata/arhiv/ГГГГ-ММ/` (перенос делает исполнитель темы, позже — `ii.py komnata zakryt`). В корне `komnata/` — только открытые темы. Ссылки на архив — по тому же имени файла.
- Шаг обсуждения: **ответы всех → общий разбор → голосование → решение учителя.** Текущий шаг пишется в шапке строкой `Шаг:`. Менять её может только координатор или исполнитель темы.

### Реплика

```
### <номер>. <Кто> · <ЧЧ:ММ> · <шаг>
<текст>
```

Номера идут подряд. Голос — отдельной строкой: `Голос: да / да с условиями (…) / нет`.

### Решение учителя

```
## Решение учителя · <ЧЧ:ММ>
<текст>
```

После решения исполнитель темы переносит его строкой в журнал (drakon-graf `docs/komanda/README.md` § 4) и в `BRIFING.md`, а в шапке комнаты ставит `Шаг: закрыто`.

## Правила для всех

1. Прочитай файл целиком, прежде чем отвечать: все видят ответы всех.
2. Отвечай только на вопрос текущего шага, коротко, и остановись. Не продолжай работу за пределами задачи.
3. Утверждения о репозиториях, библиотеках, API — со ссылкой или путём к файлу, иначе «не знаю, надо проверить». Никаких выдуманных имён.
4. Репозиторий публичный: **никаких персональных данных** учеников и учителя. Сведения о реальности и об учителе лежат в приватном репозитории; комната только ссылается на них.
5. Чужие реплики не переписывать. Не согласен — новая реплика.

## Как каждый слушает и говорит

| Кто | Слушает | Говорит |
|---|---|---|
| Алиса, DeepSeek | сейчас — учитель передаёт ссылку или текст файла; после `ii.py komnata` — скрипт по API Яндекса | сейчас — учитель вставляет ответ; потом — скрипт сам дописывает |
| Марьям (Claude) | читает файл из репозитория по слову учителя «комната» | дописывает и коммитит сама |
| GLM | вручную: учитель даёт ссылку на файл или его текст (может ли GLM читать raw-ссылки GitHub — надо проверить) | учитель вставляет ответ |
| Учитель | файл на GitHub или в редакторе | пишет `## Решение учителя` |
